## 二、教学目标（可检验）

1. 能说清连接器解决什么问题：无依据、无素材、凭空生成。
2. 能区分「一次性粘贴文字」与「建通道、文件持续在场」：改动源方案后重新生成，问卷信息跟着变。
3. 能独立完成添加授权、在任务中启用、授权失效重连、停止使用与解绑；知道三种启用方式分别适合什么情况。
4. 能说清权限边界三条，并在收集游戏官方素材时按最小范围使用。
5. 当堂交出产出③，对比记录能指出哪些信息只有接入材料后才准确。

## 四、`10-40'` 连接器原理（30 分钟，本场主体）

### 4.1 从问题切入（10-18'）

现场用「做一份 XX 活动报名问卷」不接任何材料生成一版，投屏结果：时间「待定」、地点「某商场」、亮点「游戏、奖品、表演」、通用蓝白表单。板书三问：它凭什么知道时间地点？凭什么知道亮点？凭什么知道该问什么？结论落在：**没有真实材料，输出只能靠编**。

### 4.2 连接器是什么（18-26'）

- **官方定义**：连接器用于将 WorkBuddy 与外部服务对接，将外部数据和能力引入 AI 工作流；配置后可在获得授权的前提下访问和操作第三方服务。
- **四类能力**（官方）：数据查询 / 服务调用 / 文件管理 / 消息通知，各配一个设计场景例子（检索官方素材文档、读取网盘图片、导入回收数据、发报名通知）。
- **两种实现形态**（官方，概念级）：MCP + CLI（标准化协议）/ Skill + CLI（内置脚本）；二者在数据收集与权限边界上遵循一致原则。**不讲协议细节与开发**。
- **当前支持**：QQ 邮箱、腾讯文档、腾讯乐享、腾讯会议、TAPD、腾讯网盘，以及自定义连接器（MCP）。只点名，不展开。

### 4.3 关键区分：一次性粘贴 vs 持续在场（26-33'）

| 对比项 | 复制文字进对话框 / 单次上传 | 连接器建通道 |
|---|---|---|
| 材料在哪 | 只在这一条消息里 | 整个任务期间持续在场 |
| 源文件改了 | 要重新复制一遍 | 重新生成时读到最新内容 |
| 多份材料 | 逐条贴，容易漏 | 授权范围内按需读取 |
| 跨任务复用 | 每次重来 | 通道保留，切换任务仍在 |
| 能做的动作 | 只能读这段内容 | 可读云端文件、可查数据、可发通知 |

**现场演示**：接入方案文件 → 生成问卷 → 改方案里的时间 → 重新生成 → 问卷时间跟着变。这是本场最直观的一击，也是题目文档点名的常见坑（学生直接把方案文字复制进对话框，以为这就是连接器）。

### 4.4 生命周期与权限边界（33-40'）

- **添加**：侧边栏「专家·技能·连接器」→ 连接器页签 → 卡片右上 `+` → 按提示登录、授权或配置 → 完成后即可使用。
- **三种使用方式**（官方）：
  1. 连接器管理页点「去对话」，直接发起；
  2. 创建任务时，输入框左下 `+` > 连接器，在弹窗中启用（未授权的先完成授权）；
  3. 执行任务时按需连接：输入框上方出现引导卡片，授权后自动继续执行当前任务，无需重开对话。
- **授权失效**：出现「连接器需要重新连接」卡片 → 重新连接 → 自动重试刚才失败的那一步（只重试一次）。仅授权失效才提示；网络超时、服务异常、无权限不会出现这张卡片。
- **停止使用与解绑**：任务内关闭启用状态即不再参与任务；连接器管理页可解绑；也可用对话自然语言安装、查看、卸载（内置连接器不支持卸载）。
- **权限边界三条**（官方）：每个连接器独立授权 / 不主动定时抓取 / 不超出你已有权限范围。补充：第三方业务数据仅在指令触发时按需读取；写入类操作需明确指令；对外发送、内容修改前再次确认目标与内容；不再使用时及时撤销授权。

> 讲法定位：这段是「深度拆解」的知识核心，但只到「会用、懂边界」，不到「会开发」。

## 五、`40-70'` 素材接入演示（30 分钟）

### 5.1 接入什么

| 材料 | 来源 | 接入方式 | 用在问卷哪里（对齐样例） |
|---|---|---|---|
| 第 2 节活动策划方案 | 本组产出② | 本地文件 / 腾讯文档 | 时间、地点、目标人群、报名区字段 |
| 三个活动亮点 | 方案第 5 项物料清单 | 同上 | 「最想玩什么」的选项 |
| 品牌配色与角色素材 | 游戏官网 / 网盘 | 图片文件 / 云端目录 | 问卷头部视觉与配色 |
| 官方名称与规范 | 官网资料 | 文档检索 | 题面措辞、IP 名称不写错 |

### 5.2 演示顺序

1. 先演示方式②（创建任务时启用）—— 最贴合当堂任务。
2. 再演示方式③（执行中按需连接）—— 说明不用为了一个连接器重开任务。
3. 最后演示权限确认页与「已连接」状态，带出最小权限。

### 5.3 常见坑（讲师巡场重点）

| 坑 | 表现 | 处置 |
|---|---|---|
| 把复制粘贴当连接器 | 方案文字贴进输入框，输出仍会跑偏 | 回看 4.3 的「改方案 → 重新生成」演示 |
| 授权没走完 | 卡在扫码 / 登录页，任务读不到 | 确认卡片出现已连接状态 |
| 目录或范围选错 | 读不到素材，或读到无关文件 | 按任务选最小范围，不整盘授权 |
| 素材来源不统一 | 各组自己搜图，风格与 IP 不一致 | 统一官方素材包，注明来源 |
| 授权失效 | 执行中断在半路 | 认「重新连接」卡片，不重开任务 |
| 和 Skill 混用 | 以为接了材料就能自动按规格出题 | 材料归连接器，题目结构归流程，本场只练材料 |

## 六、`70-105'` 上手实操（35 分钟）

**任务**：同一个需求「做一份本组活动的报名问卷」，做两版，对比后定稿。

| 步骤 | 动作 | 时间 |
|---|---|---|
| A 版 | 断开所有材料，直接生成一版 | 8' |
| 接入 | 挂载方案文件 + 官方素材包，确认连接状态 | 7' |
| B 版 | 接入材料后重新生成一版 | 10' |
| 对比 | 按四行填对比记录 | 6' |
| 定稿 | 补齐题量与题型，检查信息与方案一致 | 4' |

**四行对比**（直接对齐样例 `03-素材接入记录.md`）：时间地点 / 亮点选项 / 视觉风格 / 报名区字段。要求写出「哪条信息只有接材料后才准确」，不写「B 版更好」这类空话。

## 七、产出③规格与合格线

**报名问卷**，8–10 题，四类题型齐全：

| 题型 | 示例 | 信息必须来自 |
|---|---|---|
| 基本信息 | 姓名、手机、所在城市 | — |
| 报名意向 | 参加人数、偏好时间段 | 方案的活动流程 / 目标人群 |
| 需求调研 | 想看什么环节、想要什么周边 | 方案的三个活动亮点 |
| 开放题 | 对活动的期待 / 建议 1–2 题 | — |

**素材接入记录**：一张表写清「材料 / 来自哪里 / 通过什么接入 / 用在了问卷哪里」+ 接入前后四行对比 + 一句话结论。

**合格线**（题目文档四条）：

- [ ] 问卷信息与第 2 节方案一致（时间、地点、亮点对得上）
- [ ] 8–10 题，题型多样，不重复不诱导
- [ ] 使用记录写清「文件通过连接器进入工作流，持续在场」
- [ ] 能对比出「接材料」与「凭空生成」两版的质量差异

> **口径校准**：样例 `03-素材接入记录.md` 自检清单写的是「题目 6 道」，与题目规格 8–10 题不符。课前需把样例改为 8–10 题，或明确样例为简版。本大纲按 **8–10 题** 执行。

**讲师点评要点**：现场做一次「断开材料重新生成」的对比，差异最直观；点评只抓「信息对不对得上方案」，不评问卷美观。
