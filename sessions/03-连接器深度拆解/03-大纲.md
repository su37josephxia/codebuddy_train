## 二、教学目标（可检验）

1. 能说清连接器解决什么问题：无依据、无素材、凭空生成。
2. 能区分「一次性粘贴文字」与「建通道、文件持续在场」：改动源方案后更新问卷，信息跟着变。
3. 能独立完成添加授权、在任务中启用、授权失效重连、停止使用与解绑；知道三种启用方式分别适合什么情况。
4. 能用腾讯问卷连接器创建问卷、写出合规的纯文本问卷描述、取回投放链接，并回读结构、修正单题。
5. 能说清权限边界三条，理解「写入外部服务需明确指令、对外发布前二次确认」。
6. 当堂交出产出③，对比记录能指出哪些信息只有接入材料后才准确。

## 四、`10-40'` 连接器原理（30 分钟，本场主体）

### 4.1 从问题切入（10-18'）

现场断开所有材料，用腾讯问卷连接器创建一版「XX 活动报名问卷」，投屏 A 版：标题只有活动名、时间地点写「待定」、亮点多选题是「游戏、奖品、表演」、欢迎语一句套话。板书三问：它凭什么知道时间地点？凭什么知道亮点？凭什么知道该问什么？结论落在：**没有真实材料，输出只能靠编**。

> 这一版要在问卷标题里标「测试·勿投放」，且不外发链接（见 §六）。

### 4.2 连接器是什么（18-26'）

- **官方定义**：连接器用于将 WorkBuddy 与外部服务对接，将外部数据和能力引入 AI 工作流；配置后可在获得授权的前提下访问和操作第三方服务。
- **四类能力**（官方），各配一个本场能看见的例子：

| 能力 | 本场对应动作 |
|---|---|
| 数据查询 | 检索官方素材文档、读取方案 |
| 服务调用 | **通过腾讯问卷连接器创建在线问卷、回读结构、改单题** |
| 文件管理 | 读取第 2 节方案文件、官方图片 |
| 消息通知 | 把正式版投放链接发到班级群 / 交给第 4 场做落地页 |

- **本场要点**：连接器是**双向**的。输入端把真实材料接进工作流，输出端把成果写进外部服务（腾讯问卷）。学生第一次看到「AI 不只生成文件，还能在真实平台上把东西建出来」。
- **两种实现形态**（官方，概念级）：MCP + CLI（标准化协议）/ Skill + CLI（内置脚本）；二者在数据收集与权限边界上遵循一致原则。**不讲协议细节与开发**。
- **当前支持**：QQ 邮箱、腾讯文档、腾讯乐享、腾讯会议、TAPD、腾讯网盘，另有腾讯问卷等官方连接器插件，并支持自定义连接器（MCP）。只点名，不展开。

### 4.3 关键区分：一次性粘贴 vs 持续在场（26-33'）

| 对比项 | 复制文字进对话框 / 单次上传 | 连接器建通道 |
|---|---|---|
| 材料在哪 | 只在这一条消息里 | 整个任务期间持续在场 |
| 源文件改了 | 要重新复制一遍 | 重新生成时读到最新内容 |
| 多份材料 | 逐条贴，容易漏 | 授权范围内按需读取 |
| 跨任务复用 | 每次重来 | 通道保留，切换任务仍在 |
| 能做的动作 | 只能读这段内容 | 可读云端文件、可查数据、可创建问卷、可发通知 |

**现场演示**：接入方案文件 → 创建 B 版问卷 → 改方案里的时间 → 用 `update_question` 更新问卷里那道时间题 → 在线问卷跟着变。这是本场最直观的一击，也是题目文档点名的常见坑（学生直接把方案文字复制进对话框，以为这就是连接器）。

> 注意：`create_survey` 是**非幂等**写操作，每调用一次就真的新建一份问卷。演示「改方案后更新」优先用 `update_question` 改单题，不要反复重建整份问卷。

### 4.4 生命周期与权限边界（33-40'）

- **添加**：侧边栏「专家·技能·连接器」→ 连接器页签 → 卡片右上 `+` → 按提示登录、授权或配置 → 完成后即可使用。腾讯问卷连接器需扫码 / 登录授权，**课前必须完成**。
- **三种使用方式**（官方）：
  1. 连接器管理页点「去对话」，直接发起；
  2. 创建任务时，输入框左下 `+` > 连接器，在弹窗中启用（未授权的先完成授权）；
  3. 执行任务时按需连接：输入框上方出现引导卡片，授权后自动继续执行当前任务，无需重开对话。
- **授权失效**：出现「连接器需要重新连接」卡片 → 重新连接 → 自动重试刚才失败的那一步（只重试一次）。仅授权失效才提示；网络超时、服务异常、无权限不会出现这张卡片。
- **停止使用与解绑**：任务内关闭启用状态即不再参与任务；连接器管理页可解绑；也可用对话自然语言安装、查看、卸载（内置连接器不支持卸载）。
- **权限边界三条**（官方）：每个连接器独立授权 / 不主动定时抓取 / 不超出你已有权限范围。补充：第三方业务数据仅在指令触发时按需读取；**创建问卷属于对第三方服务的写入，需明确指令**；对外发布投放链接、修改已发布的问卷内容前，再次确认标题与题目；不再使用时及时撤销授权。

> 讲法定位：这段是「深度拆解」的知识核心，但只到「会用、懂边界」，不到「会开发」。

## 五、`40-70'` 素材接入演示（30 分钟）

### 5.1 接入什么

| 材料 | 来源 | 接入方式 | 用在问卷哪里 |
|---|---|---|---|
| 第 2 节活动策划方案 | 本组产出② | 本地文件 / 腾讯文档 | 问卷标题、欢迎语里的时间地点、报名区字段 |
| 三个活动亮点 | 方案第 5 项物料清单 | 同上 | 「现场最想玩什么」多选题的选项 |
| 目标人群描述 | 方案第 3 项 | 同上 | 参加人数、到场时段两题的选项 |
| 官方名称与素材调性 | 游戏官网 / 官方素材包 | 图片文件 / 文档检索 | 问卷标题、欢迎语措辞、IP 名称不写错 |

> **边界提醒**：腾讯问卷的视觉样式由平台模板决定，官方海报 / 角色图不等于能直接贴进问卷。素材的作用是让**文字信息**准确、调性一致，不强求配色还原。这条正好用来讲「连接器能接材料，但目标平台能呈现什么由平台决定」。

### 5.2 演示顺序

1. **授权**：完成腾讯问卷连接器登录，确认卡片显示已连接状态（课前先做一遍，现场只复核）。
2. **启用**：创建任务时用方式②（输入框左下 `+` > 连接器）挂上腾讯问卷连接器；方案文件与官方素材同时作为上下文接入。
3. **写问卷描述**：用纯文本 DSL 写出问卷标题 + 引导语 + 8–10 道题（语法见 5.2.1）。
4. **创建并取回链接**：连接器调用 `create_survey` → 返回 `survey_id` 与 `hash` → 拼出投放链接 `https://wj.qq.com/s2/{survey_id}/{hash}`，当场打开验证。
5. **回读与改单题**：`get_survey` 确认题目结构 → `update_question` 改一道题 → 再回读一次，说明「改的是线上那份，不是本地文件」。
6. **方式③**（可选）：执行中关闭再按需连接，演示引导卡片与自动继续。

### 5.2.1 纯文本问卷描述骨架（9 题示例）

```
蛋仔派对「夏日游园会」活动报名

欢迎报名蛋趣工作室主办的夏日游园会。活动时间 8 月周末 13:00–20:00，地点 XX 商场中庭，请按实际情况填写。

您的姓名[单行文本题]
手机号码[单行文本题]
所在城市[单行文本题]
您预计几个人一起来[单选题]
1 人
2 人
3–4 人
5 人及以上
您更倾向哪个时间段到场[单选题]
13:00–15:00
15:00–17:00
17:00–20:00
现场最想玩哪个环节[多选题]
巨型装置打卡
闯关赛
毛绒兑换
最想要的周边类型[多选题]
毛绒挂件
徽章
限定贴纸
您从哪里得知本次活动[单选题]
玩家社群
朋友推荐
校园海报
对这场活动的期待或建议[多行文本题]
```

语法要点（课前用测试问卷验证一次）：第一行是问卷标题；题目之间空一行分隔；**同一题的标题与选项之间不能空行**；选项不写 A./B. 前缀；`[单选题] [多选题] [单行文本题] [多行文本题] [段落说明]` 等为题型标记；`[必答] / [选答]`、`=== 分页 ===` 按现场版本语法追加。

### 5.3 常见坑（讲师巡场重点）

| 坑 | 表现 | 处置 |
|---|---|---|
| 把复制粘贴当连接器 | 方案文字贴进输入框，输出仍会跑偏 | 回看 4.3 的「改方案 → 更新问卷」演示 |
| 授权没走完 | 卡在扫码 / 登录页，`create_survey` 报未授权 | 课前统一授权，现场确认已连接状态 |
| 以为连接器只能读 | 只敢让它读文件，最后手工去问卷后台建表 | 明确点出「服务调用」这一类能力 |
| 官方图片当成能贴进问卷 | 花时间调配色、找头图 | 说明平台样式边界，素材只管文字信息 |
| DSL 格式写错 | 题目内空行、选项带字母前缀 → 创建失败 | 按 5.2.1 骨架写，课前验证语法 |
| 反复重建问卷 | 每改一次就 `create_survey`，留下一堆重复问卷 | 改单题用 `update_question`；A 版标「测试·勿投放」 |
| 授权失效 | 执行中断在半路 | 认「重新连接」卡片，不重开任务 |
| 和 Skill 混用 | 以为接了材料就能自动按规格出题 | 材料归连接器，题目结构归流程，本场只练材料 |

## 六、`70-105'` 上手实操（35 分钟）

**任务**：同一个需求「做一份本组活动的报名问卷」，两版都通过腾讯问卷连接器创建真实在线问卷，对比后定稿正式版投放链接。

| 步骤 | 动作 | 时间 |
|---|---|---|
| A 版 | 断开所有材料，用连接器创建一版（标题标「测试·勿投放」） | 8' |
| 接入 | 挂载方案文件 + 官方素材包，确认腾讯问卷连接器已连接 | 7' |
| B 版 | 接入材料后创建正式版，取回投放链接并当场打开 | 10' |
| 对比 | 四行对比 + `get_survey` 回读两版结构 | 6' |
| 定稿 | 用 `update_question` 修正单题，检查 8–10 题与方案一致 | 4' |

**四行对比**（写进素材接入记录）：问卷标题与欢迎语 / 时间地点题 / 亮点多选题选项 / 报名区字段（参加人数、到场时段）。要求写出「哪条信息只有接材料后才准确」，不写「B 版更好」这类空话。

**课堂纪律**：A 版链接禁止外发；两版的 `survey_id` 与链接都要登记；课后统一清理测试问卷，只保留正式版。

## 七、产出③规格与合格线

**腾讯问卷在线报名问卷**，8–10 题，四类题型齐全：

| 题型 | 示例 | 问卷题型 | 信息必须来自 |
|---|---|---|---|
| 基本信息 | 姓名、手机、所在城市 | 单行文本题 | — |
| 报名意向 | 参加人数、偏好时间段 | 单选题 | 方案的活动流程 / 目标人群 |
| 需求调研 | 想看什么环节、想要什么周边 | 多选题 | 方案的三个活动亮点 |
| 开放题 | 对活动的期待 / 建议 1–2 题 | 多行文本题 | — |

**交付三件**：

1. 正式版投放链接 `https://wj.qq.com/s2/{survey_id}/{hash}`（当场可打开、可填写）
2. **素材接入记录**：一张表写清「材料 / 来自哪里 / 通过什么接入 / 用在了问卷哪里」+ A / B 两版链接 + 四行对比 + 一句话结论
3. **问卷纯文本描述**（DSL 存档，便于复现与改单题）

**合格线**：

- [ ] 问卷信息与第 2 节方案一致（标题、时间、地点、亮点对得上）
- [ ] 8–10 题，题型多样，不重复不诱导，且**通过腾讯问卷连接器创建**（有投放链接与 `survey_id`）
- [ ] 使用记录写清「材料通过连接器进入工作流、持续在场；成果通过腾讯问卷连接器写入外部服务」
- [ ] 能对比出「接材料」与「凭空生成」两版的质量差异，并给出正式版投放链接

> **口径校准**：样例 `03-素材接入记录.md` 自检清单原写「题目 6 道」、且以 `03-报名问卷.html` 为交付物。现统一为 **8–10 题 + 腾讯问卷在线问卷**；样例 HTML 保留作**内容示意**，不是课堂交付形态。样例已同步标注。

**讲师点评要点**：现场做一次「断开材料创建 / 接入材料创建」的对比，差异最直观；点评只抓「信息对不对得上方案、链接能不能真的发出去」，不评平台皮肤。

## 八、与相邻概念的边界（贯穿全场，不单独成段）

| 概念 | 管什么 | 本场怎么讲 |
|---|---|---|
| 上传文件 / `@` 引用 | 一次性上下文 | 4.3 对比表，作为对照物 |
| 连接器（输入端） | 材料从哪来 | 读方案、读官方素材 |
| 连接器（输出端） | 成果写到哪去 | 腾讯问卷连接器建出在线问卷 |
| Skill | 事情按什么流程做 | 只点名，不展开（第 2 场已讲） |
| 专家 | 用什么专业眼光做 | 只点名，不展开（第 4 场讲） |
| 资料库 | 资料集中管理与检索 | 只提一句，与外部服务通道区分 |

板书收口：**连接器管材料，也管把成果写进外部服务**。万能公式的完整整合留到第 4 场，本场不提前收。
