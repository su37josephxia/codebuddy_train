# 第 3 场　连接器深度拆解

> 总纲：[../../搞定设计师的AI工作台-7场培训安排.md](../../搞定设计师的AI工作台-7场培训安排.md) ｜ 工程约定：[../../AGENTS.md](../../AGENTS.md)

## 本场定位

- **时长**：120 分钟
- **核心内容**：外部资源联动原理；读取本地设计文件/图片/草图/PDF
- **本场产出**：让 AI 基于本人真实作品产出内容
- **上游输入**：第 2 场的标准化设计输出与质量对比
- **下游交付**：整理好的个人作品素材包 → 第 4–7 场实战统一使用

## 时间分配

| 时间 | 环节 | 内容要点 |
|---|---|---|
| 0-15' | 复盘与答疑 | 作业展示：Skill 输出质量对比 |
| 15-45' | 连接器原理 | 对接外部软件、文件、资源的桥梁；解决"无依据、无素材、脱离本人作品" |
| 45-80' | 素材接入演示 | 读取海报、产品模型、空间效果图、草图、PPT、PDF 的操作要点与常见坑 |
| 80-110' | 上手实操 | 上传个人作品，让 AI 基于真实作品生成内容 |
| 110-120' | 小结与作业 | 整理个人作品素材包，供后续场次使用 |

## 本目录放什么

- `03-slides.html` — 本场演示稿（复制 `templates/ppt-template.html` 后改写）

通用演示样例放 `assets/samples/`；素材包模板放 `resources/handouts/`。
