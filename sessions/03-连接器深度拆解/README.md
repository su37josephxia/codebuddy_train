# 第 3 场　连接器深度拆解

> 总纲：[../../搞定设计师的AI工作台-7场培训安排.md](../../搞定设计师的AI工作台-7场培训安排.md) ｜ 工程约定：[../../AGENTS.md](../../AGENTS.md)

## 本场定位

- **时长**：120 分钟（两天制第 1 天第 3 场）
- **核心内容**：外部资源联动原理；接入方案文件与游戏官方素材
- **本场产出**：**产出③ 报名问卷（8–10 题 + 素材接入记录）**；当堂完成
- **核心动作**：接入第 2 节活动方案 + 游戏官方素材，先不接材料做一版、再接材料做一版，对比后定稿能发出去的报名表
- **上游输入**：第 2 场产出② 活动策划方案；开场 10 分钟补齐前一日未完成产出
- **下游交付**：产出③ 报名问卷（招募入口）→ 第 4 场做活动物料的输入
- **题目规格**：[前四节成果题目设计-游戏主题活动方向.md 第 3 节](../../resources/handouts/前四节成果题目设计-游戏主题活动方向.md) ｜ 样例：[报名问卷.html](../../assets/samples/游戏主题活动样例-蛋仔派对/03-报名问卷.html)
- **项目手册**：[../../resources/handouts/分组宣发项目执行手册.md](../../resources/handouts/分组宣发项目执行手册.md)

## 时间分配

| 时间 | 环节 | 内容要点 |
|---|---|---|
| 0-10' | 复盘与补齐 | 产出②方案展示；开场 10 分钟补齐前一日未完成产出 |
| 10-40' | 连接器原理 | 对接外部软件、文件、资源的桥梁；解决"无依据、无素材、凭空生成"；讲清"建通道、文件持续在场"而不是一次性粘贴 |
| 40-70' | 素材接入演示 | 接入第 2 节活动方案 + 游戏官方海报/角色图/场景图的操作要点与常见坑 |
| 70-105' | 上手实操 | 先不接材料生成一版报名问卷，再接入方案与素材生成一版，对比差异 |
| 105-120' | 产出收口 | 定稿 8–10 题报名问卷（基本信息/报名意向/需求调研/开放题）+ 素材接入记录 → 沉淀产出③ |
