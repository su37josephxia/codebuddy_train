# 第 3 场　连接器深度拆解

> 总纲：[../../搞定设计师的AI工作台-7场培训安排.md](../../搞定设计师的AI工作台-7场培训安排.md) ｜ 工程约定：[../../AGENTS.md](../../AGENTS.md)

## 本场定位

- **时长**：120 分钟（两天制第 1 天第 3 场）
- **核心内容**：连接器读写双向原理；接入方案文件与游戏官方素材，通过腾讯问卷连接器创建在线报名问卷
- **本场产出**：**产出③ 腾讯问卷在线报名问卷（8–10 题）+ 投放链接 + 素材接入记录**；当堂完成
- **核心动作**：接入第 2 节活动方案 + 官方素材，先不接材料创建一版问卷、再接材料创建一版，对比后定稿正式版投放链接
- **上游输入**：第 2 场产出② 活动策划方案；开场 10 分钟补齐前一日未完成产出
- **下游交付**：产出③ 投放链接（招募入口）→ 第 4 场落地页报名区按钮 / 长图报名方式
- **题目规格**：[前四节成果题目设计-游戏主题活动方向.md 第 3 节](../../resources/handouts/前四节成果题目设计-游戏主题活动方向.md) ｜ 内容示意：[报名问卷.html](../../assets/samples/游戏主题活动样例-蛋仔派对/03-报名问卷.html)（课堂实际产出为腾讯问卷在线问卷，非 HTML）
- **项目手册**：[../../resources/handouts/分组宣发项目执行手册.md](../../resources/handouts/分组宣发项目执行手册.md)

## 时间分配

| 时间 | 环节 | 内容要点 |
|---|---|---|
| 0-10' | 复盘与补齐 | 产出②方案展示；开场 10 分钟补齐前一日未完成产出 |
| 10-40' | 连接器原理 | 对接外部软件、文件、资源的桥梁；解决"无依据、无素材、凭空生成"；讲清"建通道、文件持续在场"而不是一次性粘贴；点出连接器也能把成果写进外部服务 |
| 40-70' | 素材接入演示 | 接入第 2 节方案 + 官方素材；腾讯问卷连接器授权与启用；纯文本问卷描述写法；创建并取回投放链接 |
| 70-105' | 上手实操 | 先不接材料创建一版在线问卷，再接入方案与素材创建一版，均通过腾讯问卷连接器，对比差异 |
| 105-120' | 产出收口 | 定稿 8–10 题在线报名问卷（基本信息/报名意向/需求调研/开放题）+ 投放链接 + 素材接入记录 → 沉淀产出③ |
