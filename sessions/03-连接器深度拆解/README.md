# 第 3 场　连接器深度拆解

> 总纲：[../../搞定设计师的AI工作台-7场培训安排.md](../../搞定设计师的AI工作台-7场培训安排.md) ｜ 工程约定：[../../AGENTS.md](../../AGENTS.md)

## 本场定位

- **时长**：120 分钟（两天制第 1 天第 3 场）
- **核心内容**：先按官方 MCP 文档讲清 MCP（定义、USB 类比、四项核心价值、三种角色）；**现场接入一个公共 MCP 做实验 F**（Fetch，备选 Time）；再引入连接器，按官方 Connector 文档讲定义、四类能力、配置与使用全生命周期、信息收集与权限边界；接入方案文件与游戏官方素材，通过腾讯问卷连接器创建在线报名问卷
- **本场产出**：**产出③ 腾讯问卷在线报名问卷（8–10 题）+ 投放链接 + 素材接入记录**；当堂完成
- **核心动作**：接入第 2 节活动方案 + 官方素材，先不接材料创建一版问卷、再接材料创建一版，对比后定稿正式版投放链接
- **上游输入**：第 2 场产出② 活动策划方案；开场 10 分钟补齐前一日未完成产出
- **下游交付**：产出③ 投放链接（招募入口）→ 第 4 场落地页报名区按钮 / 长图报名方式
- **题目规格**：[前四节成果题目设计-游戏主题活动方向.md 第 3 节](../../resources/handouts/前四节成果题目设计-游戏主题活动方向.md) ｜ 内容示意：[报名问卷.html](../../assets/samples/游戏主题活动样例-蛋仔派对/03-报名问卷.html)（课堂实际产出为腾讯问卷在线问卷，非 HTML）
- **项目手册**：[../../resources/handouts/分组宣发项目执行手册.md](../../resources/handouts/分组宣发项目执行手册.md)

## 时间分配

| 时间 | 环节 | 内容要点 |
|---|---|---|
| 0-10' | 复盘与补齐 | 产出②方案展示；开场 10 分钟补齐前一日未完成产出 |
| 10-40' | MCP 与连接器原理 | 先讲清 MCP：官方定义 / **开放通用协议标准的定位与归属** / USB-C 规范类比 / 协议三部分组成 / 四项核心价值 / 三种角色 / 公共 MCP 从哪来；**主实验 F：接入官方参考实现 Fetch**（备选 Time），四步配置、看状态灯、同一句话问两次、填记录卡；再由实验引入连接器，先点破「**MCP ≠ 连接器**」（一句话、五行区别表、完整链路、三个误区、极简记忆版），按官方 Connector 文档讲定义、两种实现形态、四类能力、口径修正；操作与边界三块移到演示段带练 |
| 40-70' | 素材接入演示 | §5.0 带练：授权与权限清单、三种使用方式、失效重连、一次性粘贴 vs 持续在场、信息收集与权限边界；接入第 2 节方案 + 官方素材；纯文本问卷描述写法；创建并取回投放链接；**含 2 个嵌入式对照 A / B（启用前后 / 断开再问）** |
| 70-105' | 上手实操 | 先不接材料创建一版在线问卷，再接入方案与素材创建一版，均通过腾讯问卷连接器，对比差异 |
| 105-120' | 产出收口 | 定稿 8–10 题在线报名问卷（基本信息/报名意向/需求调研/开放题）+ 投放链接 + 素材接入记录 → 沉淀产出③ |

> 腾讯问卷连接器为会话内官方连接器插件（当前状态 `auth-required`，课前需完成扫码 / 登录授权），能力为 `create_survey` / `get_survey` / `update_question` / `list_answers`，问卷用纯文本 DSL 描述。
>
> **基础讲解口径（2026-11-26 重编）**：按上面官方文档的六节顺序讲，写入侧用官方的「服务调用」+「用户写入数据需明确指令确认」，不使用自造的「双向通道」说法；官方内置连接器清单（QQ 邮箱、腾讯文档、腾讯乐享、腾讯会议、TAPD、腾讯网盘等）与课堂用的腾讯问卷连接器插件分开讲，授权方式以现场页面提示为准。
>
> **顺序重排（2026-11-26 七次调整）**：原理段改为「先把 MCP 讲清楚 → 现场接入一个公共 MCP 做实验 → 再引入连接器」。MCP 段以官方 MCP 文档为准；主实验 F 由讲师接入官方参考实现 Fetch，学生只观察、填记录卡，不接需要密钥或能对外发消息的服务；连接器的配置与使用、信息收集与权限边界讲解移到 `40-70'` 带练，明细完整保留在 `03-大纲.md` §5.0.1。演示稿页序同步重排，仍 18 页，总时长与产出规格不变。
>
> **基础讲解重编（2026-11-26 九次调整，本次）**：按 [MCP 与 WorkBuddy 连接器的区别](https://www.doubao.com/thread/xrWP0PZw2j4F6Qowr) 重写 `03-大纲.md` §4.2 / §4.4 / §4.5 与演示稿 P03 / P04 / P07 / P08。核心补齐三点：MCP 是**开放通用协议标准、不属于任何产品、跨产品通用**；**MCP ≠ 连接器**（很多连接器底层用 MCP，但还有 Skill + CLI 型不走 MCP）；用五行区别表、完整链路、三个误区与成对 USB-C 类比讲清关系，不再只讲「协议层 / 产品层分工」。官方 Connector 口径与腾讯问卷实践不变，仍 18 页、30 分钟。
