## 二、MCP 是什么（P03–P04）

| 页 | 版式 | 标题 | 上屏要点 |
|---|---|---|---|
| P03 | S03 · split-statement | MCP 是什么 | 左（官方定义）：MCP（Model Context Protocol，模型上下文协议）用于将外部工具和服务接入 WorkBuddy；它标准化了 AI 系统与数据源的交互方式，让模型拿到更准确的上下文<br>官方类比：AI 的「USB 接口」，像电脑通过 USB 连接外设<br>右（官方核心价值四项）：上下文共享 / 工具调用 / 可组合工作流 / 数据控制，各配一句人话<br>脚注：规矩统一之后，服务方实现一次，支持协议的应用都能接 |
| P04 | S04 · stack-build | 一次调用怎么走 | 三种角色：Host 宿主（WorkBuddy）/ Client 客户端（应用内通信组件）/ Server 服务器（暴露工具与数据的小服务）<br>四步链路：说一句需求 → 判断要用哪个工具 → 通过 MCP 找到 Server 上的工具 → 结果回传成为上下文，模型据此回答<br>公共 MCP 从哪来：腾讯云 MCP 市场一键安装、官方参考实现（Fetch / Filesystem / Git / Memory / Time 等）、MCP Registry<br>一句：工具是挂上去的，接上前模型手里没有这件工具 |

## 四、连接器（P07–P12）

| 页 | 版式 | 标题 | 上屏要点 |
|---|---|---|---|
| P07 | S03 · split-statement | 从 MCP 到连接器 | 左：协议层管怎么描述工具、怎么调用、怎么回传；实验里那段配置、状态灯与多出来的 fetch 都在这里<br>右：产品层补上授权与登录、启用与关闭开关、连接状态与失效重连、独立授权与最小权限、界面可见可管理、失败提示与重试<br>类比一行：MCP ≈ USB-C 接口规范，连接器 ≈ 一个具体的 U 盘<br>收口：协议管怎么接，连接器管接什么和能不能接<br>脚注：官方两处印证——腾讯乐享授权页写「通过乐享知识库 MCP」，「自定义连接器」本质是安装自定义 MCP 服务 |
| P08 | S03 · split-statement | 连接器是什么 | 左（官方定义原文）：连接器用于将 WorkBuddy 与外部服务对接，将外部数据和能力引入 AI 工作流；配置后可在获得授权前提下访问和操作第三方服务<br>三要素：AI 工作流 / 外部服务 / 授权<br>右（官方补充三句）：两种形态 MCP + CLI（标准化协议）与 Skill + CLI（内置脚本），数据收集与权限边界一致；已支持 QQ 邮箱、腾讯文档、腾讯乐享、腾讯会议、TAPD、腾讯网盘等，另支持自定义连接器，新增后隐私协议条款同步更新<br>脚注：课堂用的腾讯问卷连接器是会话内插件，授权以现场页面提示为准 |
| P09 | S15 · grid-reveal | 连接器能做的四类事 | 官方四列：数据查询（从外部数据源获取信息｜查询数据库、检索文档｜本场读方案与素材）/ 服务调用（调用第三方 API 完成操作｜发送邮件、创建日程｜本场创建在线问卷，重点）/ 文件管理（访问云端存储与文件系统｜读取网盘文件、上传附件｜本场读方案文件与官方图片）/ 消息通知（与即时通讯工具集成｜发送企业微信或飞书消息｜本场把投放链接交到后续物料）<br>一句官方原文：在任务中调用外部服务的能力<br>脚注：服务调用包含写入；用户写入数据需明确指令确认 |
| P10 | S15 · grid-reveal | 复制粘贴与建通道的区别 | 五行对比：材料在哪 / 源文件改了 / 多份材料 / 跨任务复用 / 能做的动作<br>左栏「只在这一条消息里、要重新复制、逐条贴容易漏、每次重来、只能读这段」<br>右栏「整个任务持续在场、重新生成读到最新、按需读取、通道保留、可读可查可创建可通知」<br>脚注：断开材料时，输出只能靠编；把方案文字复制进对话框，也不等于接入 |
| P11 | S11 · four-cards | 从添加到停止使用 | ① 添加（官方 4 步）：侧边栏「专家·技能·连接器」→ 连接器页签 → 卡片右上「+」→ 按提示登录、授权或配置<br>② 三种使用方式：管理页「去对话」/ 创建任务时「+ > 连接器」/ 执行中按需连接并自动继续当前任务<br>③ 授权失效重连：认「需要重新连接」卡片，只自动重试那一步；网络超时、服务异常、无权限不会出现卡片<br>④ 停止使用 / 解绑 / 对话管理：任务内关启用状态；管理页解绑；对话里可安装、查看、卸载，内置连接器不支持卸载<br>脚注：授权页要看清权限清单（QQ 邮箱 4 项 / 腾讯乐享 3 项），连接完成显示绿色圆点与「去对话」 |
| P12 | S15 · grid-reveal（双栏） | 接上之后的数据边界 | 左栏官方「信息收集与使用」四行：第三方账号标识（必要）/ 授权凭据（必要）/ 第三方业务数据（必要，仅在指令触发时按需读取）/ 用户写入数据（非必要，需明确指令确认）<br>右栏权限边界三条：每个连接器独立授权 / 不主动定时抓取 / 不超出已有权限范围<br>脚注：连接器自身读写不消耗积分，理解汇总外部数据才消耗；对外发送与内容修改前再次确认目标对象与内容 |
