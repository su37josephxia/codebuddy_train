# 第 7 场　模块 3：作品集与竞赛展板输出 + 总结结业

> 总纲：[../../搞定设计师的AI工作台-7场培训安排.md](../../搞定设计师的AI工作台-7场培训安排.md) ｜ 工程约定：[../../AGENTS.md](../../AGENTS.md)

## 本场定位

- **时长**：120 分钟
- **核心内容**：三步结构化工作流；综合实战；知识点复盘与答疑
- **本场产出**：作品集片段 / 展板结构稿 1 份（结业交付）
- **上游输入**：第 6 场的完整设计文案 + 前 6 场全部作业链路
- **下游交付**：结业产出、进阶学习路径、课后巩固任务

> 结业要求：需体现「连接器 + Skill + 专家」的完整搭配链路。
> 考核维度：功能选型 30% / 输出专业度 30% / 搭配链路可复现 20% / 文案与排版规范 20%。

## 时间分配

| 时间 | 环节 | 内容要点 |
|---|---|---|
| 0-15' | 复盘与答疑 | 文案作业互评，提炼可复用句式与规范 |
| 15-40' | 核心原理与工作流 | 作品集/展板核心是结构规范、逻辑清晰、重点突出；三步走：连接器导入整套作品 → 作品集结构化梳理 Skill 生成框架 → 作品集/竞赛展板专家提炼亮点 |
| 40-45' | 综合任务发布 | 现场完成一份作品集片段或展板结构稿 |
| 45-100' | 综合实战 | 全流程独立操作，讲师巡场答疑，重点纠正功能混用与调用顺序问题 |
| 100-115' | 复盘与答疑 | 三大组件知识点复盘；高频问题：功能混用误区、素材上传权限、单专家与专家团选择、Skill 调用优先级 |
| 115-120' | 结业与后续 | 结业说明、进阶学习路径、课后巩固任务 |
