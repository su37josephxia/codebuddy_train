## 本场定位

- **时长**：120 分钟（两天制第 2 天第 3 场，结业场，**老师不授课、只组织路演与评分**）
- **核心内容**：把整场活动做成竞演 PPT 并路演（三大组件综合，不知识点授课）
- **本场产出**：**产出⑦ 竞演 PPT（8–10 页可翻页）+ 5 分钟路演**；《XX 游戏主题活动成果包》7 阶段成册（结业交付）
- **核心动作**：把前六节成果讲成"为什么这么用 AI"，争夺团队奖
- **上游输入**：前六节全部产出（宣讲 / 方案 / 报名 / 物料 / 互动工具 / 数据报告）
- **下游交付**：结业产出（成果包电子档当场带走）、进阶学习路径
- **产出规格**：[后三节产出设计-活动执行与复盘.md 第 7 节](../../resources/handouts/后三节产出设计-活动执行与复盘.md) ｜ 样例：[竞演PPT.html](../../assets/samples/后三节产出样例-蛋仔派对/07-竞演PPT.html)
- **项目手册**：[../../resources/handouts/分组宣发项目执行手册.md](../../resources/handouts/分组宣发项目执行手册.md)

> 结业要求：竞演 PPT 需体现「连接器 + Skill + 专家」的完整搭配链路，并有专门一页讲清三大组件怎么用。
> 知识考核维度：功能选型 30% / 输出专业度 30% / 搭配链路可复现 20% / 文案与排版规范 20%。
> 团队奖项：最佳品牌契合奖 / 最佳视觉呈现奖 / 最佳提案奖。

## 时间分配（老师不授课）

| 时间 | 环节 | 内容要点 |
|---|---|---|
| 0-10' | 任务发布 | 发布竞演 PPT 规格：8–10 页可翻页，覆盖前六节成果 |
| 10-60' | 实践：竞演 PPT | 把整场活动做成竞演 PPT：活动概念、策划方案、报名与物料、现场互动、数据复盘、**组件链路专页**、团队分工、结语；讲师巡场答疑 |
| 60-90' | 路演准备 | 组内演练 5 分钟讲解，统一说法与数据 |
| 90-115' | 结业路演与评奖 | 每组 5 分钟展示 + 2 分钟问答，按知识四维 + 三个团队奖评分与点评 |
| 115-120' | 结业与后续 | 结业说明、进阶学习路径、成果包电子档当场带走 |
