# 第 7 场　模块 3：作品集与竞赛展板输出 + 总结结业

> 总纲：[../../搞定设计师的AI工作台-7场培训安排.md](../../搞定设计师的AI工作台-7场培训安排.md) ｜ 工程约定：[../../AGENTS.md](../../AGENTS.md)

## 本场定位

- **时长**：120 分钟（两天制第 2 天第 3 场，结业场）
- **核心内容**：三步结构化工作流；综合实战；知识点复盘与提案路演
- **本场产出**：**物料⑦ 宣发提案展板 + 项目复盘**；《XX 游戏宣发物料包》7 件成册（结业交付）
- **上游输入**：第 6 场物料⑥ + 前 6 场全部物料链路
- **下游交付**：结业产出（物料包电子档当场带走）、进阶学习路径
- **项目手册**：[../../resources/handouts/分组宣发项目执行手册.md](../../resources/handouts/分组宣发项目执行手册.md)

> 结业要求：物料包需体现「连接器 + Skill + 专家」的完整搭配链路，并附项目复盘。
> 知识考核维度：功能选型 30% / 输出专业度 30% / 搭配链路可复现 20% / 文案与排版规范 20%。
> 团队奖项：最佳品牌契合奖 / 最佳视觉呈现奖 / 最佳提案奖。

## 时间分配

| 时间 | 环节 | 内容要点 |
|---|---|---|
| 0-15' | 复盘与答疑 | 物料⑥互评，提炼可复用句式与规范 |
| 15-40' | 核心原理与工作流 | 提案展板核心是结构规范、逻辑清晰、重点突出；三步走：连接器导入整套物料 → 结构化梳理 Skill 生成框架 → 展板专家提炼亮点 |
| 40-45' | 综合任务发布 | 现场把 7 场产物整理成《XX 游戏宣发物料包》并制作提案展板 |
| 45-90' | 综合实战 | 物料成册 + 展板制作 + 项目复盘（写清每件物料的组件搭配链路）；讲师巡场答疑 |
| 90-115' | 提案路演与评奖 | 每组 5 分钟提案展示，按知识四维 + 三个团队奖互评与讲师点评 |
| 115-120' | 结业与后续 | 结业说明、进阶学习路径、物料包电子档当场带走 |
