# 第 5 场　模块 1：AI 辅助设计创意与方案迭代

> 总纲：[../../搞定设计师的AI工作台-7场培训安排.md](../../搞定设计师的AI工作台-7场培训安排.md) ｜ 工程约定：[../../AGENTS.md](../../AGENTS.md)

## 本场定位

- **时长**：120 分钟（两天制第 2 天第 1 场）
- **核心内容**：创意 Skill + 专业专家组合；发散/迭代/选题三类搭配
- **本场产出**：**物料⑤ 3 套差异化宣发创意方案 + 1 个主方案**；当堂完成
- **上游输入**：第 4 场万能公式 + 物料④ 搭配决策 + 物料① Brief 卡
- **下游交付**：物料⑤ 主方案 → 第 6 场宣发文案实战的输入
- **项目手册**：[../../resources/handouts/分组宣发项目执行手册.md](../../resources/handouts/分组宣发项目执行手册.md)

> 从本场起进入三大场景实战，只用「创意」链路。

## 时间分配

| 时间 | 环节 | 内容要点 |
|---|---|---|
| 0-20' | 复盘与公式回顾 | 三大组件协同公式过一遍，明确本场只用"创意"链路 |
| 20-50' | 核心原理 | 创意发散不靠盲聊 AI，靠功能组合实现定向、差异化、符合专业审美的输出 |
| 50-80' | 三种搭配逻辑 | 简单发散：灵感发散 Skill + 专业单专家；多风格迭代：风格迭代 Skill + 审美专家；复杂竞赛：启动专家团多维度拆解 |
| 80-108' | 实战演练 | 围绕本组 Brief 定向发散 → 风格定位 → 产出 3 套差异化宣发创意方案（主题/视觉风格/核心文案/取舍理由） |
| 108-120' | 投票定稿与物料收口 | 组内投票选出 1 个主方案 → 沉淀物料⑤ |
