## 四、授课段详细设计（0-27'）

### 0-5'　① 专家及专家团概念定义

- **目标**：5 分钟建立"是什么"，不展开操作。
- **内容要点**：
  - **专家**：被固定了专业身份的 AI，设定角色、背景、审美标准与行业规范，输出带明确视角。常见三类：策划 / 文案 / 视觉专家。
  - **专家团**：多个专家按分工组织，任务先拆成几块，各角色分头完成再汇总。
  - **关系**：专家解决"谁来做、什么标准"，专家团解决"怎么拆、谁配合"。
- **讲法提示**：用本组角色分工做类比，一句带过；不打开平台演示，用法放到 17' 以后。

### 5-12'　② 和 Skill 的差异

- **目标**：把本节最容易混淆的两个东西分清楚。学生很容易把专家当成"另一个 Skill"。
- **内容要点**（投影核心对照表）：

| 维度 | Skill | 专家 / 专家团 |
| --- | --- | --- |
| 固化的是什么 | 流程与规范：这件事按哪几步做 | 身份与判断标准：谁来做、按什么眼光做 |
| 稳定性来自哪 | 结构约束，输出不漏项 | 角色设定，视角不跑偏 |
| 典型产出 | 一份结构完整的方案、纪要 | 有调性的文案、风格统一的视觉、多角色协作的物料套 |
| 协同方式 | 一个流程，一键调用 | 多个角色，分工、并行、汇总 |
| 使用入口 | 技能市场 / 内置能力 | 专家中心 / 专家团 |
| 适合的活 | 步骤稳定、重复度高、有明确验收标准 | 需要专业判断、审美取舍、多角色配合 |

- **三者的边界**（同一张投影上补三行，为后面的公式埋线）：

| 组件 | 解决什么问题 | 一句话 |
| --- | --- | --- |
| 连接器 | 材料从哪来 | 把真实素材接进工作流 |
| Skill | 事情按什么流程做 | 把重复工序固化下来 |
| 专家 | 用什么专业眼光做 | 把专业视角固定下来 |

- **讲法提示**：不要下"专家是更高级的 Skill"这类结论，两者是不同维度。用一句话收口：**Skill 管流程，专家管眼光，连接器管材料。** 让学生记住各自解决什么问题，比记住定义更重要。

### 12-17'　③ 使用场景

- **目标**：从"是什么"转向"什么时候用"，给判断标准，不做功能罗列。
- **内容要点**：

| 场景 | 该用什么 | 为什么 |
| --- | --- | --- |
| 写一份结构固定的方案、纪要 | Skill | 步骤稳定，要求不漏项 |
| 接入方案、官方素材、真实数据 | 连接器 | 有材料，输出才不发空 |
| 写一段有品牌调性的文案、定一版视觉风格 | 单专家 | 需要固定的专业视角和审美标准 |
| 一次出齐文案、海报、落地页，且彼此要对得上 | 专家团 | 多角色分工，统一约束下汇总 |
| 任务简单、只要一个结果 | 单专家即可 | 拆成团反而增加协调成本 |

- **判断口诀**（板书）：**一件事一个视角找专家，一整套物料多个视角找专家团，流程重复找 Skill，需要真材料找连接器。**
- **讲法提示**：这一节是后面"万能公式"的预热，只讲选型逻辑，不讲操作。学生能说出"这件事该找谁"就够了。

### 17-23'　④ 使用方法（案例：校园毕业设计展）

- **目标**：用一个非游戏案例，让学生看见单专家与专家团的输出差异。案例统一为**校园毕业设计展物料**：一份宣传文案、一张海报长图、一个活动落地页。本段以演示为主，快速跑过。
- **内容要点**：
  1. **单专家跑一版**：调用一个文案专家，输入"为校园毕业设计展写一份宣传文案"，要求主题名、三条 Slogan、一段社媒短文。展示输出，学生看的是：有没有专业视角、语气是否统一、结构是否齐。
  2. **专家团跑一版**：同一个需求，先拆成三步板书出来：
     - 文案：主题名 / Slogan / 社媒短文 / 邀请函
     - 视觉：海报长图的配色、版式、主视觉元素
     - 结构：落地页的区块划分与报名区
     然后交给专家团分工完成，汇总成一套。学生看的是：三件物料之间的信息是否一致、主题和 Slogan 有没有互相打架。
  3. **并排对比**：耗时、完整度、专业度、物料间一致性，四项当场打分。
- **关键口径**：**案例只用毕业设计展，不碰游戏。** 学生在后面实践环节做的才是自己的游戏主题活动，这里不提前给答案。
- **讲法提示**：拆任务的板书一定要写在演示之前。让学生看到"专家团不是把一句话丢进去等结果，而是先把活拆清楚"。这也是后面实践中要他们照做的动作。

### 23-27'　⑤ 创建专家与专家团（现场建一个简单专家）

- **目标**：选 A，真创建。带学生从零建一个简单专家，建立"我也能配一个"的信心。专家团的创建讲配置思路，不在现场完整搭团。时间紧，只做"建专家 + 跑一句"，改配置对比改为口述。
- **内容要点**：

**专家配置六项**（投影，作为填写清单）：

| 配置项 | 写什么 | 毕业设计展文案专家示例 |
| --- | --- | --- |
| 名称 | 一眼知道干什么 | 毕设展文案专家 |
| 身份设定 | 角色、经验、擅长领域 | 资深校园活动文案，做过多年毕业展传播 |
| 专业视角 | 看这件事的标准 | 年轻、有设计感、不用套话 |
| 工作流程 | 接到任务先做什么、后做什么 | 先定主题名，再写 Slogan，最后写社媒短文 |
| 输出规范 | 格式、篇幅、语气、检查项 | 主题名 1 个、Slogan 3 条、短文 150 字内，末尾自检语气统一 |
| 知识库（可选） | 挂参考资料 | 历届毕设展海报与文案样例 |

- **现场动作**：照着六项，带全班建一个"毕设展文案专家"，保存后跑一句"写一个叫'边界'的毕设展文案"，当场看输出。改一项配置（比如把"年轻"改成"庄重"），再跑一遍，让学生看到配置如何改变输出。
- **专家团配置思路**（讲清单，不现场搭）：团名称 + 角色清单（文案 / 视觉 / 结构）+ 每个角色的职责与交付物 + 协作顺序 + 统一约束。统一约束里必须写清"主题、亮点、时间地点、Slogan 四样，所有成员用同一份"。
- **讲法提示**：这是本场"我也能做"的落点。强调不用凭空想专家配置，把自己平时怎么带人、怎么定标准写出来，就是一个专家。专家团的配置同理，把自己组的分工写清楚就是团的配置。

## 五、讨论及实践段详细设计（27-45'）

> **45 分钟收窄口径**：当堂只完成**宣传文案**一件物料的单专家版与专家团版双版对比。海报长图、活动落地页两件改为对照样例讲解思路，不要求当堂产出。完整物料包规格保留在下方，供课后参照与第 5–7 场实践使用。

### 27-30'　⑥ 实践任务发布

- **形式**：各组按第 2 节方案，为自己认领的游戏主题活动做**宣传文案**。同一份需求，先单专家做一版，再专家团做一版，对比后定稿。
- **输入材料**：第 2 节方案的物料清单 + 第 3 节报名问卷（后续落地页要用）+ 前 3 节全部成果。
- **当堂产出**：宣传文案（主题名 / Slogan 3 条 / 社媒短文 / 报名邀请函）+ 双版对比记录。海报长图与落地页对照样例讲解，不在当堂制作。
- **物料包完整规格**（投影展示，作参照，非当堂要求）：

| 件 | 文件 | 规格 |
| --- | --- | --- |
| 1 | `宣传文案.md` | 活动主题名 / Slogan 3 条 / 社媒短文 / 报名邀请函 |
| 2 | `海报长图.html` | 750px 宽，含主题、亮点、时间地点、报名方式 |
| 3 | `活动落地页.html` | 至少 6 区块（首屏 / 介绍 / 亮点 / 日程 / 报名区 / FAQ），报名区嵌入第 3 节问卷 |
| 4 | `单专家与专家团对比记录.md` | 按下表填，写清最终选哪个及理由 |

- **对比记录表**（投影展示）：

| 对比项 | 单专家 | 专家团 |
| --- | --- | --- |
| 完成耗时 | | |
| 结构完整度 | | |
| 文案专业度 | | |
| 物料间一致性 | | |
| 最终选哪个，为什么 | | |

- **评判口径**（投影展示，全程可见）：

| 维度 | 权重 | 判断标准 |
| --- | --- | --- |
| 文案完整度 | 30% | 主题名 / Slogan 3 条 / 短文 / 邀请函齐不齐 |
| 专业度 | 30% | 有明确视角、调性统一、不用套话 |
| 信息一致性 | 20% | 时间、亮点、Slogan 与第 2 节方案对得上 |
| 决策说理 | 20% | 对比记录能说清两版差异与选择理由 |

### 30-40'　上手实践

- **两段走**：
  - 30-35'：单专家版。各组用自己创建的专家，围绕同一份宣传文案需求做一版，留档。
  - 35-40'：专家团版。先把"文案 / 视觉 / 结构"三步写在纸上，再交给专家团分工，汇总成一版。
- **讲师巡场，重点纠偏**：不拆任务直接把一句话丢给专家团；两版文案调性不一致；对比记录只写"专家团更好"没有理由。
- **提醒时间节点**：40' 进入讨论。

### 40-43'　对比讨论

- 各组对着两版输出，围绕三问讨论：
  1. 哪版信息更齐？差在哪里？
  2. 三件物料之间，时间、亮点、Slogan 对不对得上？
  3. 如果只做一件物料，你会选单专家还是专家团？做一整套呢？

### 43-45'　万能公式总结与产出收口

- **万能公式**（板书，全场最后一条）：

```
连接器（拿素材） + Skill（定流程） + 专家（保专业） = 高质量定制化成果
```

- **收口动作**：各组在对比记录末尾写下一句"我们组后续采用的搭配策略"，宣传文案定稿，按 `组号-游戏名-宣传文案` 命名，当堂收齐。
- **用途交代**：这份文案是第 5 场现场互动工具的素材来源，也是第 7 场竞演 PPT 的组成部分。海报长图与活动落地页对照样例讲解思路，后续实践中补齐。无课后作业。

## 八、设计逻辑说明

- **认知递进**：概念定义 → 与 Skill 划清边界 → 使用场景 → 看别人怎么用 → 自己建一个 → 自己动手做。六步从认识到动手，逐层推进。
- **案例分离**：讲授段用毕业设计展，实践段用游戏主题活动。讲授只给方法，练习才给真题，避免提前讲掉答案。
- **评图式讨论**：沿用设计专业熟悉的"对比、点评、归纳"方式，让学生从两版输出的差异中自己得出结论。
- **收口定位**：本场是四节授课节的最后一节，万能公式在这里收口，后三节学生凭公式独立实践。

## 九、来源说明与课前核对

- **专家与专家团**：使用 WorkBuddy 平台内置的专家中心能力，不预制、不自建平台外的东西。
- **课前必做**：
  1. 实测专家中心，确认至少有一个现成专家和一个专家团可直接调用，作为演示兜底；
  2. 走一遍创建专家的完整流程，确认六项配置在平台上都有对应字段；
  3. 准备毕业设计展的需求描述，现场跑通单专家版与专家团版各一次。
- **风险提示**：平台专家中心的入口、分类、创建字段可能变动，开课前实测一遍。若演示专家临时不可用，切到内置能力兜底，课堂重点是"选型逻辑 + 差异判断"，不是记住某个专家的名字。
