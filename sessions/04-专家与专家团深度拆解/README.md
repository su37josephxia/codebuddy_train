# 第 4 场　专家与专家团深度拆解

> 总纲：[../../搞定设计师的AI工作台-7场培训安排.md](../../搞定设计师的AI工作台-7场培训安排.md) ｜ 工程约定：[../../AGENTS.md](../../AGENTS.md)

## 本场定位

- **时长**：**120 分钟**（授课 45' + 实践 75'；两天制第 1 天第 4 场，第 1 天收官）
- **核心内容**：单专家专业视角；专家团多角色协同；选型逻辑与协同公式
- **本场产出**：**产出④ 方案所需物料：宣传文案 + 海报长图 + 活动落地页 + 单专家 vs 专家团对比记录**；当堂完成
- **核心动作**：按第 2 节方案的物料清单，同一物料需求分别用单专家与专家团各做一版，对比后定稿
- **上游输入**：第 2 场产出② 方案物料清单 + 第 3 场产出③ 报名问卷（招募入口）+ 前 3 节全部成果
- **下游交付**：整合出**万能公式**「连接器 + Skill + 专家」+ 产出④；第 5–7 场学生据此独立实践
- **题目规格**：[前四节成果题目设计-游戏主题活动方向.md 第 4 节](../../resources/handouts/前四节成果题目设计-游戏主题活动方向.md) ｜ 样例：[活动落地页.html](../../assets/samples/游戏主题活动样例-蛋仔派对/04-活动落地页.html)
- **项目手册**：[../../resources/handouts/分组宣发项目执行手册.md](../../resources/handouts/分组宣发项目执行手册.md)

> 本场是承上启下的关键节点：前 4 场授课拆组件并整出公式，后 3 场实践用公式完成活动执行与复盘。

## 时间分配（2026-11-23 定稿口径）

> 按用户定稿六步授课顺序：概念定义 → 差异 → 场景 → 使用方法 → 创建 → 实践。**授课 45' + 实践 75'（独立计时）**，合计 120 分钟。三处变更：去掉复盘答疑、案例演示改用校园毕业设计展（游戏案例留作实践）、创建环节选真创建。

| 模块 | 时间 | 环节 | 内容要点 |
|---|---|---|---|
| 授课 | 0-8' | ① 概念定义 | 专家 = 固定专业身份的 AI；专家团 = 多角色分工协同；用本组角色分工做类比 |
| 授课 | 8-20' | ② 和 Skill 的差异 | 三列对照（Skill 工具 / 专家 Agent 型顾问 / 专家团 Team 型团队）+ 三者边界（连接器管材料 / Skill 管流程 / 专家管眼光） |
| 授课 | 20-27' | ③ 使用场景 | 场景表 + 判断口诀；什么时候用专家、什么时候用专家团 |
| 授课 | 27-38' | ④ 使用方法（案例） | 校园毕业设计展：单专家版 vs 专家团版（先拆文案/视觉/结构三步） |
| 授课 | 38-45' | ⑤ 创建专家与专家团 | 专家设计六要素（含写不好的后果）；现场建一个简单专家、跑一句、改配置再跑一遍 |
| 实践 | 0-8' | ⑥ 实践任务发布 | 物料包四件规格 + 评判口径 + 对比记录表 |
| 实践 | 8-20' | 实践 A：单专家版 | 宣传文案，用自己创建的专家做一版 |
| 实践 | 20-55' | 实践 B：专家团版 | 三件物料，先拆三步再交团，统一约束下汇总 |
| 实践 | 55-65' | 对比讨论 | 三问：哪版齐 / 信息对不对得上 / 一件还是一整套怎么选 |
| 实践 | 65-75' | 万能公式与产出④收口 | 连接器 + Skill + 专家 = 高质量定制化成果；物料包定稿 |
