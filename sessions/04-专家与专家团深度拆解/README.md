# 第 4 场　专家与专家团深度拆解

> 总纲：[../../搞定设计师的AI工作台-7场培训安排.md](../../搞定设计师的AI工作台-7场培训安排.md) ｜ 工程约定：[../../AGENTS.md](../../AGENTS.md)

## 本场定位

- **时长**：120 分钟
- **核心内容**：单专家专业视角；专家团多角色协同；选型逻辑与协同公式
- **本场产出**：同一需求下的单专家/专家团对比报告
- **上游输入**：第 3 场整理的个人作品素材包
- **下游交付**：整合出**万能公式**「连接器 + Skill + 专家」，第 5–7 场据此实战

> 本场是承上启下的关键节点：前 4 场拆组件，后 3 场用公式解决三大场景。

## 时间分配

| 时间 | 环节 | 内容要点 |
|---|---|---|
| 0-15' | 复盘与答疑 | 素材包检查，统一后续实战口径 |
| 15-45' | 单专家 | 为 AI 赋予固定设计身份（视觉/工业/环艺/作品集专家），限定专业视角、审美标准与行业规范 |
| 45-75' | 专家团 | 多角色分工协作：任务自动拆解、并行执行、整合输出；适用复杂竞赛方案、整套 VI、完整毕设、全套作品集 |
| 75-105' | 上手实操 | 同一需求分别用单专家与专家团执行，对比差异与耗时 |
| 105-120' | 协同逻辑总结 | 万能公式：连接器（拿素材）+ Skill（定流程）+ 专家（保专业）= 高质量定制化成果 |
