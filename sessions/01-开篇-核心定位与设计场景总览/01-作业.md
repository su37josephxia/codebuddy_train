# 第 1 场 · 当堂任务单 — 工作室设定与游戏 Brief

> **当堂完成，无课后作业** ｜ 物料收口：本场 105–120′ ｜ 用途：物料①，供应后续 6 场全程使用
>
> 项目说明见：[../../resources/handouts/分组宣发项目执行手册.md](../../resources/handouts/分组宣发项目执行手册.md)

## 任务一（当堂完成）：组建工作室

4–5 人一组，每位成员认领一个角色，填进下表：

| 角色 | 职责 | 组员姓名 |
|---|---|---|
| 创意总监（组长） | 把控调性、组织讨论、决策取舍 | |
| 视觉设计 | 素材整理、主视觉生成、风格基调 | |
| 文案策划 | Slogan、海报文案、色彩释义、创新点 | |
| 素材统筹 | 官方素材收集、上传、工作流记录 | |
| 提案统筹 | 物料成册、展板制作、路演陈述 | |

4 人组由组长兼提案统筹；5 人组全员各担一角。

## 任务二（当堂完成）：AI 工作台功能地图

画一张图 / 写一页文档，把你们工作室的「AI 工作台」分成三个区，每区至少填 3 行：

| 分区 | 回答的问题 | 示例（以宣发项目为例） |
|---|---|---|
| 素材区 | 我们手上有什么？ | 游戏官方海报 · 角色立绘 · 场景图 · 活动 PDF |
| 流程区 | 我们重复做什么动作？ | 风格发散 · 写 Slogan · 做主视觉 · 排展板 |
| 专业区 | 我们需要谁的标准？ | 品牌调性评审 · 视觉审美评审 · 文案规范评审 |

**合格线**：能当场说出"我们下个场要用哪个组件，解决我们的哪个动作"。

## 任务三（当堂完成）：游戏 Brief 卡

认领一款游戏后，填一页 Brief 卡，作为后续 6 场的项目输入：

| 栏目 | 填写要求 |
|---|---|
| 工作室名称 | 组名 + 一句话定位 |
| 认领游戏 | 游戏名 + 一句话介绍 |
| 调性关键词 | 3–5 个词（如：国风、写意、东方美学） |
| 目标人群 | 年龄 / 兴趣 / 消费特征，写清楚这一类人 |
| 3 个宣发痛点 | 每条含：场景 + 卡点 + 现在花的时间 |

### 痛点写法：反例 vs 正例

| 反例（不合格） | 正例（合格） |
|---|---|
| 想做出高级感 | 每次做游戏活动海报封面，风格总要试 5、6 版才能定，花 3 小时 |
| 想提高文案水平 | 写角色宣发文案时不知道围绕哪个点展开，每次磨 2 小时还是写不出重点 |
| 物料不知道怎么排 | 排宣发物料时不知道每页放什么、顺序怎么定，拖一周没进展 |

### Brief 卡提交格式

```
工作室：____ ｜ 认领游戏：____
调性关键词：____ / ____ / ____
目标人群：____
痛点 1：场景____ ｜ 卡点____ ｜ 现在花____
痛点 2：场景____ ｜ 卡点____ ｜ 现在花____
痛点 3：场景____ ｜ 卡点____ ｜ 现在花____
```

## 物料①自检清单

- [ ] 角色分工表填写完整，每人有明确角色
- [ ] 功能地图三个区都已填写，每区 ≥ 3 行
- [ ] 能说出下一场要用哪个组件解决哪个动作
- [ ] Brief 卡的调性关键词 3–5 个、目标人群具体
- [ ] 3 个痛点都具体到动作，含场景/卡点/耗时
- [ ] 物料①按 `组号-游戏名-01-工作室设定与Brief卡` 命名，当堂提交
