# 第 1 场　立项与开篇

> 总纲：[../../搞定设计师的AI工作台-7场培训安排.md](../../搞定设计师的AI工作台-7场培训安排.md) ｜ 工程约定：[../../AGENTS.md](../../AGENTS.md)

## 本场定位

- **时长**：120 分钟（两天制第 1 天第 1 场，授课节）
- **核心内容**：WorkBuddy 的基础使用（安装、界面、创建任务、对话追问、结果查看、任务管理，按官网快速上手口径）；**大模型应用脉络与智能工作台的来路（2026-11-26 改法）**；三大组件简单演示
- **本场产出**：**产出① 组队宣讲 PPT（5 页）或宣讲海报（1 张）**（当堂完成）
- **核心动作**：组队、认领游戏、定活动概念与 3 个亮点，用工作台当场生成宣讲作品，向全班讲清"我们是谁、要办什么"
- **上游输入**：无（开篇，现场分组认领网易游戏）
- **下游交付**：产出① 定下"办什么活动"→ 第 2 场 Skill 做活动策划方案的输入
- **题目规格**：[前四节成果题目设计-游戏主题活动方向.md 第 1 节](../../resources/handouts/前四节成果题目设计-游戏主题活动方向.md) ｜ 样例：[组队宣讲PPT.html](../../assets/samples/游戏主题活动样例-蛋仔派对/01-组队宣讲PPT.html)
- **项目手册**：[../../resources/handouts/分组宣发项目执行手册.md](../../resources/handouts/分组宣发项目执行手册.md)
- **开场改法**：[01-开场融汇方案-大模型应用脉络.md](./01-开场融汇方案-大模型应用脉络.md)（2026-11-26 确认并落地）

## 时间分配

| 时间 | 环节 | 内容要点 |
|---|---|---|
| 0-10' | 课程与项目发布 | 7 场课程全景、两天节奏、分组规则与游戏认领、结业要求 |
| 10-35' | 大模型应用脉络 → 智能工作台 | 三段脉络（能聊 → 能搭 → 能干）→ 产品对照表 → 品类归纳 → 三层分型 → 落点（详见 `01-大纲.md` §三） |
| 35-45' | 三大组件简单演示 | 连接器 / Skill / 专家各 3 分钟，只演示「长什么样、点了会怎样」 |
| 45-95' | WorkBuddy 上手 | 安装登录 → 认识界面 → 创建任务 → 任务对话 → 结果查看 → 任务管理（详见 `01-大纲.md` §五） |
| 95-115' | 当堂实操 | 用基础功能生成宣讲 PPT / 海报初稿 |
| 115-120' | 产出收口 | 检查初稿、收齐电子档，沉淀产出①初稿 |

> 本表按 2026-11-25 用户要求重排，与总纲原表不同。总纲 `10-40'` 行的讲法已于 2026-11-26 同步，时间结构整体重排仍待确认。
