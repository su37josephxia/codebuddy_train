# 第 6 场　模块 2：AI 批量生成专业设计文案

> 总纲：[../../搞定设计师的AI工作台-7场培训安排.md](../../搞定设计师的AI工作台-7场培训安排.md) ｜ 工程约定：[../../AGENTS.md](../../AGENTS.md)

## 本场定位

- **时长**：120 分钟
- **核心内容**：连接器素材 + 文案 Skill + 专家润色；分专业搭配规则
- **本场产出**：一份完整设计说明（含色彩释义、创新点）
- **上游输入**：第 5 场定稿的 1 个作品与创意方案
- **下游交付**：可直接用于作业/竞赛的完整文案 → 第 7 场互评与作品集使用

## 时间分配

| 时间 | 环节 | 内容要点 |
|---|---|---|
| 0-20' | 复盘与答疑 | 创意方案点评，指出"随机 Prompt"与"功能组合"的差距 |
| 20-50' | 核心原理 | 普通 AI 文案模板化严重；用连接器导入个人作品素材 + 文案 Skill + 专业专家润色 |
| 50-75' | 分专业搭配规则 | 视觉/UI：作品图 + 视觉文案 Skill + 平面设计专家；产品/环艺：模型/效果图 + 产品空间 Skill + 工业/环艺专家 |
| 75-110' | 实战演练 | 完成设计说明、色彩释义、创新点、场景分析；练习学术润色、篇幅调整 |
| 110-120' | 作业布置 | 提交一份可直接用于作业/竞赛的完整文案 |
