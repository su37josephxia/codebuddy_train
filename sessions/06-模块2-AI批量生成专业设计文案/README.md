# 第 6 场　模块 2：AI 批量生成专业设计文案

> 总纲：[../../搞定设计师的AI工作台-7场培训安排.md](../../搞定设计师的AI工作台-7场培训安排.md) ｜ 工程约定：[../../AGENTS.md](../../AGENTS.md)

## 本场定位

- **时长**：120 分钟（两天制第 2 天第 2 场）
- **核心内容**：连接器素材 + 文案 Skill + 专家润色；分专业搭配规则
- **本场产出**：**物料⑥ 完整宣发文案套系**（海报 ×3、社交短文案、活动说明、色彩释义、创新点、场景分析）；当堂完成
- **上游输入**：第 5 场物料⑤ 主方案 + 第 3 场物料③ 素材包
- **下游交付**：物料⑥ → 第 7 场物料成册、展板制作与互评
- **项目手册**：[../../resources/handouts/分组宣发项目执行手册.md](../../resources/handouts/分组宣发项目执行手册.md)

## 时间分配

| 时间 | 环节 | 内容要点 |
|---|---|---|
| 0-20' | 复盘与答疑 | 创意方案点评，指出"随机 Prompt"与"功能组合"的差距 |
| 20-50' | 核心原理 | 普通 AI 文案模板化严重；用连接器导入本组游戏素材 + 文案 Skill + 专业专家润色 |
| 50-75' | 分专业搭配规则 | 视觉/UI：作品图 + 视觉文案 Skill + 平面设计专家；产品/环艺：模型/效果图 + 产品空间 Skill + 工业/环艺专家 |
| 75-108' | 实战演练 | 完成主视觉海报文案 ×3、社交短文案、活动说明、色彩释义、创新点、场景分析；练习学术润色与篇幅调整 |
| 108-120' | 物料收口 | 按物料规格整理成完整文案套系 → 沉淀物料⑥ |
