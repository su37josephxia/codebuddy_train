## 二、重点页要点全文

### P05　Skill 是什么

- 定义：把一套标准化的专业工作流程，封装成可复用的 AI 能力包。
- 工作方式：
  1. 按描述触发：每个 Skill 有一段描述，写明做什么、什么时候用；AI 平时只看描述，对得上才启用。
  2. 用到才加载：启用后才读完整指令，参考资料、模板、脚本再按需读取。
- 官方出处：
  - 博客：Equipping agents for the real world with Agent Skills（anthropic.com/engineering）
  - 规范：agentskills.io
  - 仓库：github.com/anthropics/skills
  - 注：以上为 Agent Skills 规范出处，WorkBuddy 对应关系以平台实际为准。

### P07　Skill 的三要素

| 三要素 | 写在哪里 |
|---|---|
| 标准工作流程 | `SKILL.md` 正文里的步骤说明 |
| 任务指令 | `SKILL.md` 正文里每一步的具体要求；要执行的代码放 `scripts/` |
| 输出规范 | `SKILL.md` 正文里的格式要求和检查项；长模板放 `assets/` 或 `references/` |
| 触发条件 | `SKILL.md` 开头的 `name` 与 `description` |

### P08　写方案的 Skill 选型

| 场景 | 找什么方向 | 判断标准 |
|---|---|---|
| 把活动想法展开成完整方案 | 文档 / 策划 / 方案生成类 | 能否按结构输出、8 项齐不齐、目标能否量化 |
| 方案配图 / 主视觉草图 | 海报 / 平面生成类 | 要不要出图、中文文字是否稳定 |
| 方案整理成汇报材料 | PPT / 思维导图 / Word 内置能力 | 框架先行、开箱即用 |

找 Skill 四个动作：① 搜「策划 / 方案 / 活动 / 文档」② 看描述里有没有结构化输出 ③ 装一个，用一句话需求试跑 ④ 能打开结构、能改输出规范的优先。

### P16　用 Skill 写活动策划方案

| 版本 | 做法 | 作用 |
|---|---|---|
| A 裸聊版 | 不用 Skill，直接发需求描述 | 对照基线 |
| B Skill 原版 | 用自己找到的 Skill，发同一句需求描述 | 看现成 Skill 带来什么 |
| C Skill 改造版 | 把 8 项规格写进 Skill 的输出规范，再发同一句需求描述 | 看改输出规范带来什么 |

横条：三版用同一句需求描述，8 项要求只写进 Skill。Skill 不指定，自己去技能市场找；找不到用内置文档能力兜底。
