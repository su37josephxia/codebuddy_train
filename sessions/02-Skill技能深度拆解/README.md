# 第 2 场　Skill 技能深度拆解

> 总纲：[../../搞定设计师的AI工作台-7场培训安排.md](../../搞定设计师的AI工作台-7场培训安排.md) ｜ 工程约定：[../../AGENTS.md](../../AGENTS.md)

## 本场定位

- **时长**：120 分钟（授课 60′ + 讨论及实践 60′）
- **核心内容**：Skill 定义与发展史；设计类 Skill 选型；Skill 制作方法论（工作流提取 + 四步法 + 最佳实践）
- **本场产出**：裸聊版 vs Skill 版设计说明对比 + 用 Skill 完成 1 份标准化设计输出
- **本场灵魂**：Skill = 可复用的专业工序，而非「一个更高级的按钮」
- **上游输入**：第 1 场的功能地图与 3 个设计痛点
- **下游交付**：标准化设计输出 → 供第 3 场「上传个人作品」使用

## 时间分配（定稿：60 + 60）

### 授课段 60′

| 时间 | 环节 | 内容要点 |
|---|---|---|
| 0-8′ | 复盘与答疑 | 上一场功能地图点评，抛出主线问题「设计靠灵感还是靠流程」 |
| 8-20′ | Skill 发展史 | 定义 + 必要性；三代演进（对话式 AI → 提示词技巧 → Skill） |
| 20-33′ | 先体验、后拆原理 | 裸聊 vs Skill 输出对比，拆出三要素公式 |
| 33-45′ | 设计适配 Skill 选型 | 按场景选，真实 Skill 推荐表（市场安装 / 内置） |
| 45-55′ | Skill 制作方法论 | 工作流提取法 + 四步法固化 + 六条最佳实践 |
| 55-60′ | 拆解内核与轻改造 | 看结构、改脚本、发布任务 |

### 讨论及实践段 60′

| 时间 | 环节 | 内容要点 |
|---|---|---|
| 60-70′ | 任务发布 | 双轨任务：裸聊版 + Skill 版设计说明，明确评判口径 |
| 70-95′ | 上手实践 | 学员独立完成，讲师巡场纠偏 |
| 95-110′ | 对比讨论 | 评图式三问：差异在哪 / 由哪部分结构造成 / 我的专业适合哪些 |
| 110-117′ | 成果分享 | 自愿分享，讲师归纳落点 |
| 117-120′ | 小结与作业 | 布置标准化设计输出 |
