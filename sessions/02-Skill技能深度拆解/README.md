# 第 2 场　Skill 技能深度拆解

> 总纲：[../../搞定设计师的AI工作台-7场培训安排.md](../../搞定设计师的AI工作台-7场培训安排.md) ｜ 工程约定：[../../AGENTS.md](../../AGENTS.md)

## 本场定位

- **时长**：120 分钟
- **核心内容**：Skill 定义与标准化执行逻辑；设计专属 Skill；一键标准化输出
- **本场产出**：用 Skill 完成 1 份标准化设计输出
- **上游输入**：第 1 场的功能地图与 3 个设计痛点
- **下游交付**：标准化设计输出（含「无 Skill 裸聊」对比）→ 供第 3 场作业展示

## 时间分配

| 时间 | 环节 | 内容要点 |
|---|---|---|
| 0-15' | 复盘与答疑 | 上一场功能地图点评，收集疑问 |
| 15-45' | Skill 原理 | 标准化工作流程 + 任务脚本 + 输出规范，AI 的"专业工具包" |
| 45-80' | 设计适配 Skill | 设计创意发散、设计说明撰写、作品集排版大纲、竞赛文案优化、设计报告整理 |
| 80-110' | 上手实操 | 简单任务直接调用 Skill，对比"无 Skill 裸聊"的输出差异 |
| 110-120' | 小结与作业 | 用 1 个 Skill 完成一份标准化设计输出 |
