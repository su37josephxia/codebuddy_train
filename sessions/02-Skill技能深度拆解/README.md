# 第 2 场　Skill 技能深度拆解

> 总纲：[../../搞定设计师的AI工作台-7场培训安排.md](../../搞定设计师的AI工作台-7场培训安排.md) ｜ 工程约定：[../../AGENTS.md](../../AGENTS.md)

## 本场定位

- **时长**：120 分钟（授课 60′ + 讨论及实践 60′，两天制第 1 天第 2 场）
- **核心内容**：Skill 定义与发展史；Skill 选型；Skill 制作方法论（工作流提取 + 四步法 + 最佳实践）
- **本场产出**：**产出② 活动策划方案（8 项 + 裸聊版 / Skill 原版 / Skill 改造版三版对比记录）**；当堂完成，无课后作业
- **本场灵魂**：Skill 是可复用的专业流程，背后是一套被预设好的 SOP；价值是「结构稳定、不漏项」
- **上游输入**：第 1 场产出① 组队宣讲 PPT / 海报（重点是活动概念、3 个亮点、后续物料清单）
- **下游交付**：产出② 方案（含物料清单与招募方式）→ 第 3 场报名问卷的输入
- **题目规格**：[前四节成果题目设计-游戏主题活动方向.md 第 2 节](../../resources/handouts/前四节成果题目设计-游戏主题活动方向.md) ｜ 样例：[活动策划方案.md](../../assets/samples/游戏主题活动样例-蛋仔派对/02-活动策划方案.md)
- **项目手册**：[../../resources/handouts/分组宣发项目执行手册.md](../../resources/handouts/分组宣发项目执行手册.md)

## 时间分配（定稿：60 + 60）

### 授课段 60′

| 时间 | 环节 | 内容要点 |
|---|---|---|
| 0-8′ | 复盘与答疑 | 上一场宣讲 PPT 点评，抛出主线问题「设计靠灵感还是靠流程」 |
| 8-20′ | Skill 发展史 | 定义 + 必要性 + 工作方式（按描述触发、用到才加载）；发展历程（对话式 AI → 提示词技巧 → Skill） |
| 20-33′ | 先体验、后拆原理 | 讲师演示裸聊 vs Skill 写会议纪要，拆出三要素公式，并指出三要素在 Skill 文件里的位置 |
| 33-45′ | Skill 选型 | 写方案的选型判断 + 找 Skill 四个动作为主；获取渠道、设计类工具地图带过 |
| 45-55′ | Skill 制作方法论 | 工作流提取法 + 四步法固化 + 六条最佳实践；用策划方案场景举例 |
| 55-60′ | 拆解内核与轻改造 | 打开会议纪要 Skill，改一句输出规范并重跑（任务发布挪到 60′ 后） |

### 讨论及实践段 60′

| 时间 | 环节 | 内容要点 |
|---|---|---|
| 60-70′ | 任务发布 + 找 Skill | 三版对照：A 裸聊版 / B Skill 原版 / C 把 8 项写进输出规范的改造版；三版同一句需求描述；明确方案 8 项规格 |
| 70-95′ | 上手实践 | 各组完成三版输出，讲师巡场纠偏 |
| 95-110′ | 对比讨论 | 三问：8 项齐不齐 / 差异由 Skill 哪部分结构造成 / 物料清单与宣讲第 5 页对不对得上 |
| 110-117′ | 成果分享 | 自愿分享，讲师归纳落点「结构稳定、不漏项」 |
| 117-120′ | 产出收口 | 定稿活动策划方案（C 版）+ 对比记录 → 沉淀产出② |
