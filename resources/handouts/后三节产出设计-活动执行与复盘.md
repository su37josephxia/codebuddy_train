# 后三节产出设计 · 活动执行与复盘

> **适用范围**：两天培训中，第 1–4 节为授课节（老师讲知识点 + 当堂出题），**第 5–7 节为学生实践节**（老师不授课、巡场答疑，**但学生要做完本文规定的产出**）。本文只设计后三节的产出。
>
> 前四节题目：[前四节成果题目设计-游戏主题活动方向.md](./前四节成果题目设计-游戏主题活动方向.md) ｜ 总纲：[../../搞定设计师的AI工作台-7场培训安排.md](../../搞定设计师的AI工作台-7场培训安排.md) ｜ 样例：[../../assets/samples/后三节产出样例-蛋仔派对/README.md](../../assets/samples/后三节产出样例-蛋仔派对/README.md)

## 一、后三节不是"空窗"

前四节完成的是**活动筹备**：组队宣讲立项 → Skill 做策划 → 连接器做报名 → 专家团出物料。

后三节完成的是**活动执行与复盘**——真实办一场活动，筹备完之后还有现场互动、数据复盘、结业展示这三段。老师在这三节不讲新知识点，但每组要把下面这些产出做出来，作为结业物料包的后半部分。

| 节次 | 阶段 | 核心动作 | 产出物 | 用哪个组件 |
|---|---|---|---|---|
| 第 5 节 | 活动执行 | 做现场用的互动工具 | **抽奖大转盘** + **主题互动小游戏** | Skill + 专家（代码类） |
| 第 6 节 | 活动复盘 | 收集反馈、看懂数据 | **活动调研问卷** + **数据分析报告** | 连接器 + Skill |
| 第 7 节 | 结业展示 | 把整场活动讲清楚 | **竞演 PPT** + 现场路演 | 三大组件综合 |

```
前四节  立项 → 策划 → 报名 → 物料（筹备）
                              ↓
第5节   抽奖大转盘 + 互动小游戏（现场用）
                              ↓
第6节   活动调研问卷（收集反馈）→ 数据分析报告（看懂结果）
                              ↓
第7节   竞演 PPT → 路演展示 → 结业评分
```

## 二、贯穿数据（与前四节一致）

样例组第 02 组继续用**蛋仔派对「夏日游园会」**，所有数据与前四节样例一致：

- 活动时间：8 月周末 13:00–20:00，XX 商场中庭
- 三个亮点：巨型蛋仔装置打卡 / 闯关挑战赛 / 毛绒周边兑换
- 奖品池：毛绒玩偶、限定徽章、贴纸明信片
- 报名问卷：第 3 节已产出腾讯问卷在线问卷与投放链接（前四节样例 `03-报名问卷.html` 仅作内容示意）

## 三、第 5 节　活动执行 —— 现场互动工具

### 产出物 A：抽奖大转盘

**任务描述**：做一个活动现场用来抽奖的大转盘，现场扫码或点击即可抽取奖品，奖品要与活动主题和物料清单一致。

**产出规格**：`抽奖大转盘.html`，一个能在浏览器打开、点击就转的页面，必须包含：

| 要素 | 要求 |
|---|---|
| 奖品扇区 | 6–8 个扇区，奖品来自第 2 节方案的奖品池（毛绒玩偶、限定徽章、贴纸等） |
| 交互 | 点击"开始抽奖"转盘旋转，停下后高亮中奖扇区并弹出结果 |
| 公平性 | 每个扇区等概率（或标注概率），不是固定指向某一个 |
| 主题视觉 | 用蛋仔 IP 的暖黄+橙配色，与前面物料一致 |
| 结果记录 | 至少显示"本次中奖：XXX"，可截图留证 |

**合格标准**

- [ ] 转盘能真实转动并随机停下，不是静态图
- [ ] 奖品与第 2 节方案的物料/奖品清单对得上
- [ ] 有中奖结果提示，视觉与活动主题一致
- [ ] 能说出这个工具是哪两个组件搭出来的（Skill 定流程 + 专家调细节）

**讲师巡场要点**：这是纯实践节，老师不讲课。巡场看"转盘能不能跑起来、奖品和方案对不对得上"，跑不通就提示学生检查代码类 Skill 的输出规范。

### 产出物 B：主题互动小游戏

**任务描述**：做一个与游戏 IP 主题相关的现场互动小游戏，用于等待开场或排队时暖场。

**产出规格**：`主题互动小游戏.html`，一个能在浏览器打开、能玩一局的页面，必须包含：

| 要素 | 要求 |
|---|---|
| 玩法 | 规则一句话说清，30 秒内可玩完一局（如限时点击、记忆翻牌、接蛋仔） |
| IP 关联 | 玩法或视觉紧扣认领的游戏 IP，不是通用游戏换皮 |
| 计分 | 有分数或结果反馈 |
| 重玩 | 有"再玩一次"按钮 |
| 主题视觉 | 与活动物料配色一致 |

**合格标准**

- [ ] 游戏能完整玩一局，有开始、计分、结束、重玩
- [ ] 玩法或视觉与认领的游戏 IP 明确相关
- [ ] 规则简单，现场玩家不用学就能玩
- [ ] 能在 30 分钟内由学生独立完成（不要求复杂开发）

**讲师巡场要点**：不要求做出复杂游戏，能玩、有 IP 关联、有计分即可。重点看学生能否把"现场互动需求"拆成"规则/视觉/计分"三块交给 AI。

## 四、第 6 节　活动复盘 —— 调研与数据

### 产出物 A：活动调研问卷

**任务描述**：活动结束后，做一份**满意度调研问卷**，收集到场玩家的反馈（注意：这跟第 3 节的"报名问卷"不同——报名问卷是活动前收报名信息，这份是活动后收满意度）。

**产出规格**：`活动调研问卷.html`，8–10 道题，必须包含：

| 题型 | 示例 |
|---|---|
| 满意度评分 | 对活动整体、三个亮点分别打分（1–5 分） |
| 单选 | 你最喜欢哪个环节？ |
| 多选 | 你希望下次增加什么内容？ |
| 开放题 | 最想对我们说的一句话 |

**合格标准**

- [ ] 8–10 道题，含评分、单选、多选、开放题
- [ ] 题目对应第 2 节方案的三个亮点（能看出哪个环节受欢迎）
- [ ] 与第 3 节报名问卷明确区分（这份问满意度，那份收报名信息）
- [ ] 题目不带诱导、不重复

**讲师巡场要点**：提示学生"你要从这份问卷里得到什么结论"，倒着设计题目——想看哪个亮点受欢迎，就设那道题。这是"用连接器 + Skill 做调研"的实战。

### 产出物 B：数据分析报告

**任务描述**：拿问卷的（模拟）回收数据，做一份数据分析报告，用图表说清"活动办得怎么样、哪里该改"。

**产出规格**：`数据分析报告.html`，一份带图表的网页报告，必须包含：

| 模块 | 要求 |
|---|---|
| 数据概览 | 回收份数、整体满意度平均分 |
| 亮点分析 | 三个亮点的满意度对比（图表） |
| 最受欢迎环节 | 单选结果（图表） |
| 改进建议 | 多选题高频项 + 开放题高频词 |
| 结论与建议 | 3 条可执行建议，指向下次活动 |

**合格标准**

- [ ] 有至少 2 个图表（柱状/饼图均可），不是纯文字
- [ ] 图表数据与问卷题目对应，不是编的
- [ ] 结论是"可执行的建议"，不是"活动很成功"这种空话
- [ ] 能说清"数据是通过连接器导入的，报告由 Skill 结构化生成"

**讲师巡场要点**：数据是模拟的（样例里给一组），重点是学生能否把"问卷结果 → 图表 → 结论"这条链走通。跑通了就是"用 AI 做数据分析"的真实体验。

## 五、第 7 节　结业展示 —— 竞演 PPT

### 产出物：竞演 PPT + 路演

**任务描述**：把整场活动（前六节的全部成果）做成一份竞演 PPT，向全班路演，争夺团队奖。

**产出规格**：`竞演PPT.html`，8–10 页可翻页幻灯片，必须讲清：

| 页 | 内容 |
|---|---|
| 1 封面 | 组名 + 活动名称 + Slogan |
| 2 活动概念 | 办什么、给谁办、为什么 |
| 3 策划方案 | 目标、流程、亮点（来自第 2 节） |
| 4 报名与物料 | 报名问卷 + 三件物料展示（来自第 3、4 节） |
| 5 现场互动 | 大转盘 + 小游戏演示截图（来自第 5 节） |
| 6 数据复盘 | 调研问卷结论 + 数据分析图表（来自第 6 节） |
| 7 组件链路 | 用了哪些 Skill / 连接器 / 专家，怎么搭配的 |
| 8 团队与分工 | 5 个角色各干了什么 |
| 9–10 结语 | 一句话总结 + 致谢 |

**合格标准**

- [ ] 8–10 页，覆盖前六节全部成果
- [ ] 有一页专门讲"三大组件怎么搭配的"（知识掌握的证据）
- [ ] 前后数据一致（活动名、时间、亮点、满意度不互相打架）
- [ ] 能现场 5 分钟讲完

**结业路演**：每组 5 分钟展示 + 2 分钟问答，用竞演 PPT 讲。评分沿用总纲的知识四维 + 三个团队奖（最佳品牌契合 / 最佳视觉呈现 / 最佳提案）。

**讲师组织要点**：这是结业节，老师不授课，只组织路演和评分。重点看学生能不能把"做了什么"讲成"为什么这么用 AI"。

## 六、全七节产出总览（结业物料包清单）

| 节次 | 阶段 | 产出物 | 形态 |
|---|---|---|---|
| 第 1 节 | 立项 | 组队宣讲 PPT / 海报 | 可翻页 PPT |
| 第 2 节 | 策划 | 活动策划方案 | Markdown 文档 |
| 第 3 节 | 报名 | 在线报名问卷 + 投放链接 + 素材接入记录 | 腾讯问卷在线问卷 + 文档 |
| 第 4 节 | 物料 | 宣传文案 / 海报长图 / 活动落地页 | 文档 + 网页 |
| 第 5 节 | 执行 | 抽奖大转盘 + 主题互动小游戏 | 可交互网页 |
| 第 6 节 | 复盘 | 活动调研问卷 + 数据分析报告 | 网页表单 + 图表报告 |
| 第 7 节 | 展示 | 竞演 PPT + 路演 | 可翻页 PPT |

**结业时每组带走一整套**：从立项、策划、报名、物料，到现场互动、数据复盘、结业竞演——这是一个活动从想法到落地的完整闭环，也是学生"用 AI 工作台干完一件真事"的证据链。
