# 前四节成果题目设计 · 游戏主题活动方向

> **适用范围**：两天培训中，**第 1–4 节为授课节（老师讲 + 当堂出题），第 5–7 节为学生实践节（学生自己完成任务，不再命题）**。本文只设计前四节的成果题目。
>
> 总纲：[../../搞定设计师的AI工作台-7场培训安排.md](../../搞定设计师的AI工作台-7场培训安排.md) ｜ 样例：[../../assets/samples/游戏主题活动样例-蛋仔派对/README.md](../../assets/samples/游戏主题活动样例-蛋仔派对/README.md)

## 一、为什么换成这个方向

原来的题目用了"设定卡、Brief、风格基调板、主视觉"这类设计行业术语，对软件研发和 AI 培训背景的人不直观。换成**办一场游戏主题活动/展会**这条线，产出物都是通用职场里看得懂的东西：

| 原表述（设计行业） | 现表述（通用职场） |
|---|---|
| 工作室设定卡 + Brief 卡 | 活动需求清单 + 受众调研问卷 |
| 风格基调板 | 宣传文案包（主题名 / Slogan / 短文 / 邀请函） |
| 素材包 + 主视觉 | 活动宣传海报长图 |
| 单专家 vs 专家团对比报告 | 活动落地页（含单专家 / 专家团对比记录） |

四个知识点不变：**开篇认知 → Skill → 连接器 → 专家团**。只是每项练习的成果换成你熟悉的形态。

## 二、贯穿案例

- **每组自选一款网易游戏 IP**，围绕它策划一场线下主题活动或展会。
- 可选活动类型：主题展 / 玩家见面会 / 电竞赛 / 新版本发布会 / 校园快闪。
- 四节课的成果串成一条完整链路：

```
第1节 需求清单 + 调研问卷
   ↓（问卷结论决定宣传说什么）
第2节 宣传文案包
   ↓（文案 + 官方素材）
第3节 活动海报长图
   ↓（前面所有成果汇总）
第4节 活动落地页 + 三大组件公式
   ↓
第5–7节 学生实践：自己做 PPT / 展板 / 路演（不再命题）
```

## 三、四节课题目总表

| 节次 | 知识点 | 当堂题目 | 交付文件 | 考察什么 |
|---|---|---|---|---|
| 第 1 节 | 开篇认知：WorkBuddy 是什么、三大组件 | 写活动需求清单 + 设计受众调研问卷 | `活动需求清单.md`、`受众调研问卷.html` | 能不能把"办个活动"拆成明确需求 |
| 第 2 节 | Skill：标准流程 + 输出规范 | 裸聊 vs Skill 两版宣传文案，固化成文案包 | `宣传文案包.md`（含对比记录） | 能不能看出 Skill 带来的格式稳定 |
| 第 3 节 | 连接器：导入真实文件与图片 | 用官方游戏素材做活动海报长图 | `海报长图.html` + 导出 PNG | 能不能区分"有素材"和"凭空生成" |
| 第 4 节 | 专家团：多角色协同 | 把前三项整合成活动落地页 | `活动落地页.html` + 对比记录 | 能不能说清单专家与专家团的差别 |

## 四、第 1 节　开篇认知

### 题目：活动需求清单 + 受众调研问卷

**任务描述**：各组自选一款网易游戏，策划一场线下主题活动。先写清楚"这场活动到底要做什么"，再设计一份问卷去验证受众想不想来。

**输入材料**：无，从零开始。

**产出物规格**

1. `活动需求清单.md`，一个表格，至少 6 项：

| 字段 | 说明 |
|---|---|
| 活动名称 | 一句话说清是什么活动 |
| 目标人群 | 谁来，具体到年龄/兴趣 |
| 活动目标 | 要达成什么（如到场 200 人 / 新增关注 500） |
| 时间地点 | 大致安排 |
| 活动亮点 | 3 条 |
| 成功标准 | 怎么算办成了 |

2. `受众调研问卷.html`，8–10 道题，必须包含：
   - 单选 3 题（如"你更喜欢哪类活动"）
   - 多选 2 题（如"你愿意为哪些周边付费"）
   - 开放题 1–2 题（如"你最想在现场看到什么"）
   - 其余题型自定

**合格标准**

- [ ] 需求清单的"成功标准"是可衡量的，不是"办得热闹"
- [ ] 问卷题目不重复、不带诱导性
- [ ] 问卷结果能直接指导后面的宣传文案（比如知道该主打哪个亮点）
- [ ] 能说出"哪个组件能帮我做哪一步"

**讲师点评要点**：重点看"需求拆得清不清"，不要求做得漂亮。这是认知节，目标是让学生明白 AI 工作台不是聊天工具，而是能按需求装配的工作台。

**常见坑**：学生一上来就写"办个很酷的活动"——要求退回，先写清人群和目标。

## 五、第 2 节　Skill

### 题目：活动宣传文案包

**任务描述**：同一段活动介绍，先用普通对话写一遍，再用 Skill 写一遍，对比差异后固化成一套能直接用的宣传文案。

**输入材料**：第 1 节的需求清单 + 问卷结论（重点看受众最想要什么）。

**产出物规格**：`宣传文案包.md`，包含三部分

1. **两版对比记录**

| 对比项 | 裸聊版 | Skill 版 |
|---|---|---|
| 主题名 | | |
| Slogan | | |
| 格式是否统一 | | |
| 是否有 AI 套话 | | |

2. **宣传文案包（Skill 版）**
   - 活动主题名 1 个
   - Slogan 3 条（要求句式一致）
   - 社媒短文 3 条（朋友圈 / 微博 / 小红书各 1）
   - 报名邀请函 1 份（含时间、地点、亮点、报名方式）

3. **一句话结论**：Skill 到底带来了什么。

**合格标准**

- [ ] 3 条 Slogan 句式一致，不是三条毫无关系的句子
- [ ] 文案里没有"燃爆""史诗""震撼来袭"这类通用套话
- [ ] 文案能对应问卷结论（受众想要什么，文案就说什么）
- [ ] 对比记录能指出差异来自 Skill 的哪一部分

**讲师点评要点**：Skill 的价值是"格式统一、稳定产出"，不是"写得更有创意"。点评时抓这个点，别跑偏到文采上。

**常见坑**：学生把 Skill 当"高级按钮"，只点不检查输出规范——巡场时要求打开 Skill 看一眼输出规范再改。

## 六、第 3 节　连接器

### 题目：活动宣传海报长图

**任务描述**：把第 2 节的文案和游戏的官方素材合在一起，做一张手机上看的活动宣传长图。

**输入材料**：第 2 节文案包 + 从游戏官网下载的官方素材（海报、角色图、场景图、活动规则 PDF 等）。

**产出物规格**

1. `海报长图.html`，宽度 750px，至少包含 5 个板块：

| 板块 | 内容 |
|---|---|
| 头部 | 活动主题名 + 一句 Slogan |
| 亮点区 | 3 个活动亮点，配官方素材图 |
| 信息区 | 时间、地点、对象 |
| 福利区 | 现场有什么、报名能得到什么 |
| 底部 | 报名方式 + 二维码位置 |

2. 导出 PNG 一份，命名 `海报长图.png`。

3. 一段**素材使用记录**：用了哪几张素材、怎么导入的、有素材和没素材的输出差在哪。

**合格标准**

- [ ] 长图信息完整，一眼能看懂"什么活动、什么时候、在哪、怎么报名"
- [ ] 用的是游戏官方素材，不是凭空生成的通用图
- [ ] 手机上看得清（字号、间距）
- [ ] 素材使用记录写清了"素材走连接器进入工作流"

**讲师点评要点**：这节的核心是"真实素材进来，输出才不像通用模板"。现场做一次"去掉素材重新生成"的对比，差异会非常直观。

**常见坑**：学生直接拖一张图进对话框，以为这就是连接器——要说明连接器是"建通道，文件持续在场"，不是一次性传图。

## 七、第 4 节　专家团

### 题目：活动落地页 + 单专家 / 专家团对比

**任务描述**：把前三节的成果整合成一个活动落地页。同一个需求分别用单专家和专家团各做一版，对比后再定稿。

**输入材料**：第 1 节需求清单、第 2 节文案包、第 3 节海报长图与素材。

**产出物规格**

1. `活动落地页.html`，至少包含 6 个区块：

| 区块 | 内容 |
|---|---|
| 首屏 | 活动主题名 + Slogan + 主视觉 |
| 活动介绍 | 一段话说清是什么活动 |
| 亮点 | 3 条，配图 |
| 日程 | 时间轴 |
| 报名区 | 表单字段（姓名、手机、人数） |
| 常见问题 | 3 条 FAQ |

2. `对比记录.md`，对比单专家与专家团：

| 对比项 | 单专家 | 专家团 |
|---|---|---|
| 完成任务耗时 | | |
| 结构完整度 | | |
| 文案专业度 | | |
| 视觉协调性 | | |
| 最终选哪个，为什么 | | |

**合格标准**

- [ ] 落地页 6 个区块齐全，信息前后一致
- [ ] 报名表单字段合理，不是摆设
- [ ] 对比记录说清了两版差异，决策有理由
- [ ] 能复述万能公式：连接器（拿素材）+ Skill（定流程）+ 专家（保专业）

**讲师点评要点**：这是四节课的收口。把"三大组件怎么搭配"讲透，让学生带着公式进入后三节实践。

**常见坑**：专家团不拆任务就直接用，输出互相打架——要求先写"文案、视觉、结构"三步，再交给专家团并行。

---

## 八、后三节怎么处理（不命题）

第 5–7 节是**学生实践时间**，不再出新题目。学生用前四节的成果继续完成：

| 节次 | 学生自己做的事 | 老师做什么 |
|---|---|---|
| 第 5 节 | 用前四节成果制作活动介绍 PPT | 巡场答疑，不讲课 |
| 第 6 节 | 制作现场展板、完善物料 | 巡场答疑 |
| 第 7 节 | 小组路演展示，互评 | 组织评分 |

> 这三节不需要老师设计题目，只需要给评分表。评分表沿用总纲的知识四维 + 三个团队奖。

## 九、与前四节知识点的对应关系（讲师速查）

| 节次 | 知识点 | 题目暗含的"组件思维" |
|---|---|---|
| 第 1 节 | 工作台是什么 | 先拆需求，再决定用什么工具 |
| 第 2 节 | Skill | 重复的事固化为标准流程，输出才稳定 |
| 第 3 节 | 连接器 | 真实素材进来，输出才不模板化 |
| 第 4 节 | 专家团 | 多角色协同，结构 / 文案 / 视觉各有标准 |
