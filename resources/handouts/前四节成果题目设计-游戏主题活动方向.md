# 前四节成果题目设计 · 游戏主题活动方向

> **适用范围**：两天培训中，**第 1–4 节为授课节（老师讲 + 当堂出题），第 5–7 节为学生实践节（学生自己完成任务，不再命题）**。本文只设计前四节的成果题目。
>
> 总纲：[../../搞定设计师的AI工作台-7场培训安排.md](../../搞定设计师的AI工作台-7场培训安排.md) ｜ 样例：[../../assets/samples/游戏主题活动样例-蛋仔派对/README.md](../../assets/samples/游戏主题活动样例-蛋仔派对/README.md)

## 一、设计主线：办一场游戏主题活动的完整流程

这一版的关键改动：**每节课的核心动作，直接产出该节课该有的作品，作品之间就是真实办活动的先后顺序**。

| 节次 | 核心动作 | 对应作品 | 用哪个组件做 |
|---|---|---|---|
| 第 1 节 | **组队宣讲**：组队、认领游戏、定活动、向全班宣讲 | **宣讲 PPT（或宣讲海报）** | 开篇认知（现场演示工作台能力） |
| 第 2 节 | **Skill 策划**：把"想办什么"展开成完整方案 | **活动策划方案** | Skill |
| 第 3 节 | **连接器招募**：接入真实方案与素材，做报名表 | **报名问卷** | 连接器 |
| 第 4 节 | **专家团出物料**：把方案要的东西一次性做出来 | **方案所需物料**（文案 / 海报长图 / 落地页） | 专家团 |

四个知识点完全不变：**开篇认知 → Skill → 连接器 → 专家团**。变的是每件作品都对应一个真实动作，学生能记住"这节课我做了什么"。

```
第1节 组队宣讲（宣讲PPT/海报）
   ↓ 定下"办什么活动"
第2节 Skill → 活动策划方案
   ↓ 方案里写清了要哪些物料、怎么招募
第3节 连接器 → 报名问卷
   ↓ 招募入口 + 官方素材进工作流
第4节 专家团 → 方案所需物料（文案/海报长图/落地页）
   ↓ 三大组件公式收口
第5–7节 学生实践：自己做活动介绍 PPT / 展板 / 路演（不再命题）
```

## 二、贯穿案例

- **每组自选一款网易游戏 IP**（建议 6 款：逆水寒 / 蛋仔派对 / 阴阳师 / 第五人格 / 永劫无间 / 光·遇），围绕它策划一场线下主题活动或展会。
- 可选活动类型：主题展 / 玩家见面会 / 电竞赛 / 新版本发布会 / 校园快闪。
- 样例包用**蛋仔派对「夏日游园会」**演示，第 02 组"蛋趣工作室"完成。

## 三、四节课题目总表

| 节次 | 知识点 | 当堂题目 | 交付文件 | 考察什么 |
|---|---|---|---|---|
| 第 1 节 | 开篇认知 | 组队 + 认领游戏 + 定活动，做宣讲 PPT / 海报 | `组队宣讲PPT.html`（或宣讲海报） | 能不能定下"办什么活动"，分工是否明确 |
| 第 2 节 | Skill | 用 Skill 把活动想法展开成完整策划方案 | `活动策划方案.md`（含裸聊 vs Skill 对比） | 能不能看出 Skill 让方案结构稳定、不漏项 |
| 第 3 节 | 连接器 | 接入第 2 节方案 + 官方素材，做报名问卷 | `报名问卷.html` + 素材使用记录 | 能不能区分"接入真实材料"和"凭空生成" |

## 四、第 1 节　开篇认知 —— 组队宣讲

### 题目：组队 + 认领游戏 + 定活动，做一份宣讲 PPT / 海报

**任务描述**：现场分组（4–5 人/组），每组认领一款网易游戏，商量要办一场什么线下活动，然后做一份宣讲 PPT（或一张宣讲海报），向全班讲清楚"我们是谁、要办什么、为什么要办"。

**为什么要放在第 1 节**：开篇节的核心是让学生明白"AI 工作台不是聊天工具，是能装配出成果的工作台"。宣讲作品就是现场演示的产物——一句话需求，当场变成一份像样的 PPT / 海报，学生立刻建立直觉。

**输入材料**：无，从零开始。

**产出物规格**（二选一，推荐 PPT）

**A. 组队宣讲 PPT** — 5 页，可用工作台现场生成：

| 页 | 内容 |
|---|---|
| 1 封面 | 组名 + 口号 + 认领的游戏 IP + 活动名称 |
| 2 团队 | 成员与角色分工（组长/策划/视觉/文案/统筹，可兼任） |
| 3 活动概念 | 要办什么活动、为什么选这款游戏、给谁办 |
| 4 活动亮点 | 3 个核心亮点 |
| 5 后续计划 | 这场活动需要用 AI 产出哪些物料（为第 2–4 节埋伏笔） |

**B. 宣讲海报**（1 张）—— 把上面信息浓缩成一张海报，适合组数多、时间短时选用。

**合格标准**

- [ ] 组名、成员、角色、游戏 IP、活动名称齐全
- [ ] 活动概念说清"办什么、给谁办"，不是"办个很酷的活动"
- [ ] 第 5 页列出了后续要产出的物料清单
- [ ] 作品是用 AI 工作台生成的，人工只做微调

**讲师点评要点**：认知节，看"有没有用工具、信息全不全"，**不要求设计精美**。抓一个点讲透：工作台 ≠ 聊天框，它能按需求装配出成果。

**常见坑**：学生一上来手工做 PPT 或空谈创意——要求必须用工作台生成，先定"办什么活动"再动手。

## 五、第 2 节　Skill —— 活动策划方案

### 题目：用 Skill 把活动想法展开成完整策划方案

**任务描述**：把第 1 节宣讲里定的活动概念，用 Skill 展开成一份结构化的活动策划方案。同一个需求先用普通对话写一遍，再用 Skill 写一遍，对比差异后定稿。

**输入材料**：第 1 节的宣讲 PPT / 海报（重点是"活动概念 + 亮点 + 后续物料清单"）。

**产出物规格**：`活动策划方案.md`，包含两部分

1. **两版对比记录**

| 对比项 | 裸聊版 | Skill 版 |
|---|---|---|
| 结构是否完整（8 项齐不齐） | | |
| 有没有漏项 | | |
| 格式是否统一 | | |
| 是否有 AI 套话 | | |

2. **活动策划方案（Skill 版）**，至少 8 项：

| 项 | 说明 |
|---|---|
| 活动背景 | 为什么办这场活动 |
| 活动目标 | 可量化（到场人数 / 传播量 / 新增关注） |
| 目标受众 | 人群画像 |
| 活动流程 | 时间轴（几点做什么） |
| 场地与物料 | 场地需求 + 需要的物料清单 |
| 预算与资源 | 粗略估算 |
| 风险与预案 | 至少 2 条 |
| 成功标准 | 怎么算办成了 |

**合格标准**

- [ ] 方案 8 项齐全，由 Skill 生成
- [ ] 活动目标可量化，不是"办得热闹"
- [ ] 对比记录能指出差异来自 Skill 的哪一部分（输出规范 / 固定结构）
- [ ] 方案里的"物料清单"与第 1 节宣讲第 5 页对得上

**讲师点评要点**：Skill 的价值是**结构稳定、不漏项**，不是"写得更有创意"。点评抓这个点，别跑偏到文采。

**常见坑**：学生把 Skill 当"高级按钮"，只点不检查输出规范——巡场时要求打开 Skill 看一眼输出规范再改。

## 六、第 3 节　连接器 —— 报名问卷

### 题目：接入真实方案与素材，做一份报名问卷

**任务描述**：把第 2 节的活动策划方案、以及游戏的官方素材接入工作流，做一份能直接发出去的报名问卷。同一个需求，先不接材料生成一版，再接入材料生成一版，对比差异。

**输入材料**：第 2 节活动策划方案 + 游戏官方素材（官网海报、角色图、场景图等）。

**产出物规格**

1. `报名问卷.html`，8–10 道题，必须包含：

| 题型 | 示例 |
|---|---|
| 基本信息 | 姓名、手机、所在城市 |
| 报名意向 | 参加人数、偏好的时间段 |
| 需求调研 | 想看什么环节、想要什么周边（对应活动亮点） |
| 开放题 | 对活动的期待 / 建议 1–2 题 |

2. **素材使用记录**（一段话或一个表）：接入了哪些文件、通过什么方式接入、有材料和没材料两版的差别在哪。

**合格标准**

- [ ] 问卷信息与第 2 节方案一致（时间、地点、亮点对得上）
- [ ] 题目 8–10 道，题型多样，不重复不诱导
- [ ] 使用记录写清"文件通过连接器进入工作流，持续在场"
- [ ] 能对比出"接材料"和"凭空生成"两版的质量差异

**讲师点评要点**：这节的核心是**真实材料进来，输出才不发空**。现场做一次"断开材料重新生成"的对比，差异非常直观。

**常见坑**：学生直接把方案文字复制进对话框，以为这就是连接器——要说明连接器是"建通道、文件持续在场"，不是一次性粘贴。

## 七、第 4 节　专家团 —— 方案所需物料

### 题目：把方案要的物料一次性做出来

**任务描述**：按第 2 节方案的"物料清单"，把活动真正要用的物料做出来。同一个物料需求分别用单专家和专家团各做一版，对比后再定稿。

**输入材料**：第 2 节方案（物料清单）+ 第 3 节报名问卷（招募入口）+ 前 3 节全部成果。

**产出物规格**：一个"物料包"，至少 3 件

1. `宣传文案.md`：活动主题名 / Slogan 3 条 / 社媒短文 / 报名邀请函
2. `海报长图.html`：750px 宽，含主题、亮点、时间地点、报名方式（问卷入口）
3. `活动落地页.html`：至少 6 区块（首屏 / 介绍 / 亮点 / 日程 / 报名区 / FAQ），报名区嵌入第 3 节问卷
4. `单专家与专家团对比记录.md`：

| 对比项 | 单专家 | 专家团 |
|---|---|---|
| 完成耗时 | | |
| 结构完整度 | | |
| 文案专业度 | | |
| 物料间一致性 | | |
| 最终选哪个，为什么 | | |

**合格标准**

- [ ] 至少 3 件物料，与第 2 节方案里的物料清单对得上
- [ ] 物料之间信息一致（时间、亮点、Slogan 不互相打架）
- [ ] 落地页报名区嵌入了第 3 节的报名问卷
- [ ] 对比记录说清两版差异，决策有理由
- [ ] 能复述万能公式：连接器（拿素材）+ Skill（定流程）+ 专家（保专业）

**讲师点评要点**：四节课的收口。把"三大组件怎么搭配"讲透，让学生带着公式进入后三节实践。

**常见坑**：专家团不拆任务就直接用，输出互相打架——要求先写"文案 / 视觉 / 结构"三步，再交给专家团并行。

---

## 八、后三节怎么处理（不命题）

第 5–7 节是**学生实践时间**，不再出新题目。学生用前四节的成果继续完成：

| 节次 | 学生自己做的事 | 老师做什么 |
|---|---|---|
| 第 5 节 | 用前四节成果制作活动介绍 PPT | 巡场答疑，不讲课 |
| 第 6 节 | 制作现场展板、完善物料 | 巡场答疑 |
| 第 7 节 | 小组路演展示，互评 | 组织评分 |

> 这三节不需要老师设计题目，只需要给评分表。评分表沿用总纲的知识四维 + 三个团队奖。

## 九、讲师速查：每节"知识点—动作—作品—组件"对应

| 节次 | 知识点 | 核心动作 | 作品 | 用哪个组件 | 一句话检验 |
|---|---|---|---|---|---|
| 第 1 节 | 开篇认知 | 组队宣讲 | 宣讲 PPT / 海报 | 工作台演示 | 定没定下"办什么活动" |
| 第 2 节 | Skill | 展开方案 | 活动策划方案 | Skill | 8 项齐不齐、格式稳不稳 |
| 第 3 节 | 连接器 | 招募入口 | 报名问卷 | 连接器 | 信息对不对得上方案 |
| 第 4 节 | 专家团 | 出物料 | 文案 / 长图 / 落地页 | 专家团 | 物料间一不一致、能否说清公式 |
