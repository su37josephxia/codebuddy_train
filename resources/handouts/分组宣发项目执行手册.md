# 分组宣发项目执行手册

> 适用：两天集中制 7 场培训 ｜ 总纲：[../../搞定设计师的AI工作台-7场培训安排.md](../../搞定设计师的AI工作台-7场培训安排.md)
>
> **一句话**：每组是一家"乙方工作室"，认领一款网易游戏，用两天 7 场课完成一套《XX 游戏宣发物料包》，结业时提案路演。
>
> **最新口径（2026-11-23）**：**第 1–4 节为授课节并当堂命题，第 5–7 节为学生实践节、不再命题**。前四节题目采用"游戏主题活动"方向，**每节一个真实动作、一件作品**：第 1 节组队宣讲 → 宣讲 PPT / 海报；第 2 节 Skill → 活动策划方案；第 3 节连接器 → 报名问卷；第 4 节专家团 → 方案所需物料（宣传文案 / 海报长图 / 活动落地页），详见 [前四节成果题目设计-游戏主题活动方向.md](./前四节成果题目设计-游戏主题活动方向.md)。本手册下方"游戏宣发物料包"7 件口径作为**原始设计稿保留**，与新题目方向不一致时以新文档为准。配套样例：[蛋仔派对样例产出包](../../assets/samples/游戏主题活动样例-蛋仔派对/README.md)。

## 一、项目设定

| 项 | 内容 |
|---|---|
| 组织单位 | 现场分组，4–5 人/组，每组即一家乙方工作室 |
| 项目任务 | 为认领的网易游戏做一套宣发物料设计，全程用 WorkBuddy 三大组件完成 |
| 时间 | 两天 7 场，每场 120 分钟；**练习即作业，当堂完成，当堂沉淀** |
| 收口机制 | 每场最后 15 分钟把练习成果整理成物料件；当天未完成的，次日开场 10 分钟补齐 |
| 最终交付 | 《XX 游戏宣发物料包》7 件成册 + 提案展板 + 项目复盘 |

## 二、分组与角色分工

4–5 人/组，设 5 个角色，可兼任（4 人组由组长兼提案统筹）：

| 角色 | 职责 | 对应三大组件 |
|---|---|---|
| 创意总监（组长） | 把控整体调性、组织讨论、决策取舍 | 专家视角 |
| 视觉设计 | 负责素材整理、主视觉生成、风格基调 | 连接器 + Skill |
| 文案策划 | 负责 Slogan、海报文案、色彩释义、创新点 | 文案 Skill + 专家润色 |
| 素材统筹 | 负责官方素材收集、上传、工作流记录 | 连接器 |
| 提案统筹 | 负责物料成册、展板制作、路演陈述 | 结构化梳理 Skill |

> 讲法提示：第 4 场讲专家团时回扣此处——"你们组现在就是一个专家团"，让多角色协同从概念变成切身经验。

## 三、游戏认领清单

建议 6 款，抽签或自选，确保各组调性差异、便于路演横向比较：

| 游戏 | 调性关键词 | 适合切入的专业 |
|---|---|---|
| 逆水寒 | 国风武侠、写意、东方美学 | 视觉传达 / 环艺 |
| 蛋仔派对 | 潮玩可爱、高饱和、年轻化 | UI / 数媒 |
| 阴阳师 | 和风唯美、精致、神秘感 | 视觉传达 |
| 第五人格 | 悬疑哥特、暗黑、戏剧张力 | 平面 / 数媒 |
| 永劫无间 | 东方动作、硬朗、竞技感 | 数媒 / 产品 |
| 光·遇 | 治愈唯美、柔和、情感化 | UI / 环艺 |

> 小组人数超过 6 组时，可两认领同一款但要求不同切入角度（如同一游戏侧重角色向 / 场景向 / 赛事向）；讲师课前确认无撞车。

## 四、七场当堂交付节奏

| 场次 | 当堂练习 | 物料收口（最后 15 分钟） | 沉淀的物料 |
|---|---|---|---|
| 1 开篇 | 组建工作室、认领游戏、画功能地图 | 写游戏 Brief 卡 | ① 工作室设定卡 + Brief 卡 |
| 2 Skill | 同一句 Slogan 裸聊版 vs Skill 版对比 | 固化 5 条 Slogan + 风格关键词表 | ② 风格基调板 |
| 3 连接器 | 上传官方素材，对比有/无素材生成差异 | 整理素材包，记录工作流 | ③ 官方素材包 + 主视觉 1 张 |
| 4 专家团 | 同一需求单专家 vs 专家团各跑一遍 | 写下本组后续搭配策略 | ④ 对比报告（含搭配决策） |
| 5 创意 | 围绕 Brief 定向发散 3 个差异化方向 | 组内投票定主方案 | ⑤ 3 套创意方案 + 主方案 |
| 6 文案 | 现场生成海报文案、色彩释义、创新点 | 按规格整理成套系 | ⑥ 完整宣发文案套系 |
| 7 展板结业 | 物料成册 + 展板制作 + 项目复盘 | 提案路演与评奖 | ⑦ 提案展板 + 项目复盘 |

## 五、物料包规格（7 件）

| 编号 | 物料 | 规格要求 | 关键验收点 |
|---|---|---|---|
| ① | 工作室设定卡 + 游戏 Brief 卡 | 1 页；组名、角色分工；游戏调性、目标人群、3 个宣发痛点 | 痛点具体到动作，不是感受 |
| ② | 风格基调板 | 5 条统一格式 Slogan + 5–8 个风格关键词 | 能看出 Skill 带来的格式一致性 |
| ③ | 官方素材包 + 主视觉 | 3–5 张官方素材 + 1 张 AI 生成主视觉 | 注明素材如何进入工作流 |
| ④ | 单专家 vs 专家团对比报告 | 1 页：两版输出、视角差异、耗时、本组搭配决策 | 决策有理由，不是二选一拍脑袋 |
| ⑤ | 3 套创意方案 + 主方案 | 每套含主题、视觉风格、核心文案、取舍理由；标注主方案 | 三套之间确有差异化 |
| ⑥ | 完整宣发文案套系 | 海报文案 ×3、社交短文案、活动说明、色彩释义、创新点、场景分析 | 覆盖全部 6 项，非模板化 |
| ⑦ | 提案展板 + 项目复盘 | 展板 1 份；复盘写清每件物料的组件搭配链路 | 链路可复现，能照着再做一遍 |

**成册要求**：7 件统一命名 `组号-游戏名-物料编号-物料名`，第 7 场收齐电子档，现场带走。

## 六、评分标准

### 知识考核（四维，每组一份，讲师评分）

| 维度 | 权重 | 看什么 |
|---|---|---|
| 功能选型是否正确 | 30% | 每件物料选用的 Skill / 连接器 / 专家是否匹配任务 |
| 输出专业度 | 30% | 物料是否符合游戏调性与设计专业规范 |
| 搭配链路是否可复现 | 20% | 项目复盘能否让他人照着重做一遍 |
| 文案与排版规范 | 20% | 文案套系与展版的结构、排版、语言规范 |

### 团队奖项（与知识考核分开计，互评 + 讲师点评）

| 奖项 | 评选口径 |
|---|---|
| 最佳品牌契合奖 | 物料最贴合所认领游戏的调性与气质 |
| 最佳视觉呈现奖 | 主视觉与展板的视觉完成度最高 |
| 最佳提案奖 | 5 分钟路演的逻辑、表达与说服力最强 |

## 七、讲师准备清单

- [ ] 游戏认领抽签卡（6 款，按组数准备）
- [ ] 工作室设定卡 / Brief 卡模板（物料①）
- [ ] 风格基调板模板（物料②）
- [ ] 各游戏官方素材包兜底（3–5 张/款，防止学员现场找不到素材）
- [ ] 对比报告模板（物料④）
- [ ] 创意方案模板（物料⑤）
- [ ] 文案套系模板（物料⑥）
- [ ] 展板结构模板与评分表（物料⑦）
- [ ] 确认第 2 场所用市场 Skill 已安装并跑通
- [ ] 第 1 天结束前检查前 4 件物料完成度，未完成的次日开场补

## 八、两天执行提醒

1. **第 1 天**主打拆组件与出公式，收齐物料①–④，讲师当晚检查完成度。
2. **第 2 天**开场 10 分钟补齐物料，随后用万能公式做创意、文案、展板。
3. 路演每组 5 分钟，超时即停；评分表当场收齐。
4. 全程不布置课后作业，成果当堂出、当堂收、当堂带走。
