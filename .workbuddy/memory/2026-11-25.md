## 上手段按官网快速上手口径重组（commit `64801ab`）

官网 WorkBuddy 文档（www.workbuddy.cn/docs/workbuddy/）的入门结构：
- `FirstTask`「开启你的第一个任务」：下载安装 → 微信扫码登录 → 新建任务 → 描述任务 → 发送执行 → 看结果（产物 / 概览-工作空间文件）。
- 四个细化页：`Create-Task` 创建任务 · `Conversation` 任务对话 · `Results` 结果查看 · `Task-Management` 任务管理。
- `Overview` 的「认识工作界面」四区：工具栏（顶）/ 侧边栏（左，任务列表+底部头像进设置）/ 对话区（中，标题栏+消息+输入框）/ 结果区（右）。
- 安装指南：`From-Beginner-to-Expert-Guide/Installation-Mac-Guide` 与 `Installation-Win-Guide`。Mac 需 macOS 12+，M 芯片选 ARM64、Intel 选 X64（未识别默认 X64）；**必须把 app 拖进 Applications，否则从 dmg 直接跑无法自动更新**。Windows 10+ x64。

§五 按官方顺序重排为 7 段共 50 分钟：安装登录 10' / 认识界面 5' / 创建任务 12' / 任务对话 8' / 结果查看 8' / 任务管理 5' / 三个基础动作 2'。关键官方口径已写入：
- **四要素**：目标是什么 / 输入是什么 / 输出格式 / 约束条件。
- **上下文四方式**：@ 引用、Cmd/Ctrl+V 粘贴截图、上传或拖拽文件、补充说明（设计场景强调贴参考图）。
- **结果区四页签**：产物 / 网页 / 工作空间文件 / 变更（Overview 说「概览+产物」，以 Results 页为准，现场核对）。
- **任务状态**：规划中 / 进行中 / 待处理 / 已完成 / 失败 / 已归档（侧边栏另有「已完成未读」「待确认」标记）。
- **回退 ≠ 编辑 ≠ 刷新**：回退只退回不重生成；编辑从该条重来；刷新只重做最后一条；三者都可能影响产物。
- 隐私边界：文件本地处理不上传；只访问主动授权文件夹；高危操作二次确认。
