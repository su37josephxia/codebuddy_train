# 第 2 节产出　活动策划方案（Skill 版，含裸聊 vs Skill 对比）

## 一、两版对比记录

同一个需求——"把蛋仔夏日游园会做成一份完整策划方案"，先用普通对话写一遍，再用 Skill 写一遍。

| 对比项 | 裸聊版 | Skill 版 |
|---|---|---|
| 结构完整度 | 只有背景和亮点，缺预算、风险、成功标准 | 8 项齐全，按固定结构输出 |
| 格式是否统一 | 段落式，长短不一 | 每项一个小标题 + 要点，格式一致 |
| 目标是否可量化 | "希望人来得多一点" | 到场 ≥300 人、扫码关注 ≥500 |
| 是否有 AI 套话 | 有："燃爆全场""超强来袭" | 无，都是具体动作和数字 |
| 物料清单是否列出 | 没提 | 单独列出 4 项物料，可直接分派 |

**一句话结论**：Skill 带来的是**固定结构 + 输出规范 + 可复用**——换个组、换个活动，套同一个 Skill 出来的东西格式一样、不漏项。裸聊版每次都不一样，全靠人盯着补。

## 二、活动策划方案（Skill 版）

### 1. 活动背景
蛋仔派对玩家有很强的线下打卡和周边收集习惯，夏日档期适合做一场轻量、可拍照、可结伴的线下游园会，把线上热度带到线下。

### 2. 活动目标
- 到场人数 ≥ 300 人
- 现场扫码新增关注 ≥ 500 人
- 社交平台相关话题 ≥ 1000 条

### 3. 目标受众
18–28 岁，喜欢潮玩与可爱画风、有线下打卡习惯的蛋仔玩家，鼓励结伴参加。

### 4. 活动流程（时间轴）

| 时间 | 环节 |
|---|---|
| 13:00–13:30 | 签到入场，领入场攻略 |
| 13:30–15:00 | 巨型装置自由打卡 |
| 15:00–17:00 | 闯关挑战赛（三轮） |
| 17:00–18:30 | 毛绒周边兑换、合影 |
| 18:30–20:00 | 游戏试玩、自由交流 |

### 5. 场地与物料
- 场地：商场中庭，约 200㎡，需电源与拍照区动线
- 物料清单（供第 4 节制作）：
  1. 腾讯问卷在线报名表（报名入口）
  2. 宣传文案（主题名 / Slogan / 短文 / 邀请函）
  3. 海报长图（线上转发 + 现场立牌）
  4. 活动落地页（信息汇总 + 报名）

### 6. 预算与资源

| 项目 | 估算 |
|---|---|
| 场地与搭建 | ¥8,000 |
| 巨型装置制作 | ¥5,000 |
| 周边奖品 | ¥4,000 |
| 物料印刷 | ¥1,500 |
| 合计 | ¥18,500 |

### 7. 风险与预案
1. **到场人数不足** → 提前在玩家社群发报名问卷，报名数 <150 时加推社媒短文。
2. **周边不够发** → 兑换区设数量上限，先到先得，并准备贴纸作为替补。
3. **现场人流过于集中** → 打卡区与闯关区分开动线，安排工作人员分流。

### 8. 成功标准
- 到场 ≥ 300 人
- 现场扫码关注 ≥ 500 人
- 社交平台话题 ≥ 1000 条
- 报名问卷回收 ≥ 400 份
