# 第 2 节产出　宣传文案包（含裸聊 vs Skill 对比）

> 样例组：第 02 组 ｜ 输入：第 1 节问卷结论（主打打卡、小红书渠道、毛绒周边）

## 一、两版对比记录

| 对比项 | 裸聊版 | Skill 版 |
|---|---|---|
| 主题名 | 蛋仔派对超级狂欢嘉年华来袭！ | 蛋仔夏日游园会 |
| Slogan | 快来玩吧超好玩 / 一起来嗨 / 惊喜不断 | ①陪蛋仔过夏天 ②一整天，玩个够 ③带上朋友一起滚 |
| 格式是否统一 | 否，三条长短不一、风格各异 | 是，统一为 6–8 字口语短句 |
| 是否有 AI 套话 | 有："超级""来袭""惊喜不断" | 无，全部是具体动作 |
| 是否对应问卷结论 | 否，没提到打卡和周边 | 是，每条都指向打卡或结伴 |

**一句话结论**：Skill 带来的是**格式统一、可复用的输出规范**，不是"写得更花"。裸聊版每次输出都不一样，Skill 版换个人调用也能保持同一套句式。
