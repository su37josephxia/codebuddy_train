## 建议浏览顺序

1. **先看宣讲 PPT**——第 1 节定下"办什么活动"，最后页列出要用 AI 做哪些物料。
2. **再看策划方案**——第 2 节把想法展开成完整方案，末尾的物料清单是第 4 节的输入。
3. **然后看报名问卷 + 接入记录**——第 3 节检验"接没接真实材料的差别"。
4. **最后看第 4 节三件物料 + 对比记录**——同一套信息在文案、长图、落地页里是否一致，以及单专家 vs 专家团的差别。

## 这条链体现了什么

```
第1节 组队宣讲：定下"办蛋仔夏日游园会" + 列出要用 AI 做的物料
   ↓
第2节 Skill 出方案：8 项策划，末尾物料清单（问卷/文案/长图/落地页）
   ↓
第3节 连接器做问卷：接入方案里的时间地点亮点 + 官方素材 → 报名表
   ↓
第4节 专家团出物料：文案/长图/落地页，三处信息完全一致，报名入口指向第3节问卷
   ↓
第5–7节 学生实践：把这套东西做成活动介绍 PPT / 展板 / 路演（不命题）
```

每一节的产出都是下一节的输入。四节课结束时，每组手里已经有一套可以直接用的活动物料；后三节只是把它们整理成 PPT 和展板去路演。

## 想让你判断的点

| 观察点 | 样例里的体现 |
|---|---|
| 动作和作品是否匹配 | 宣讲→PPT、策划→方案、招募→问卷、出物料→文案/长图/落地页，一一对应 |
| 是不是你熟悉的形态 |  PPT、策划方案、报名问卷、落地页——都是活动和软件项目里的常见交付物 |
| 当堂做不做得完 | 文字类 1 页，网页类用现成结构填充；不需要设计功底 |
| 知识点有没有被检验 | 第 2 节看裸聊 vs Skill 对比、第 3 节看素材接入对比、第 4 节看专家对比——都是"说出为什么" |
| 后三节还有没有事做 | 有，但不命题——学生自己做 PPT、展板、路演 |

> 觉得哪件重了或轻了，直接说哪一件，我调规格。
