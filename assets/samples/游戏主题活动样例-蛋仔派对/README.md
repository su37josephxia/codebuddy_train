## 建议浏览顺序

1. **先打开落地页**——看到四节课成果汇总后的最终形态。
2. **再看海报长图**——判断"当堂做一张长图"是否现实。
3. **然后看问卷网页和文案包**——判断文字类产出的颗粒度。
4. **最后看对比记录**——这是检验知识掌握的关键。

## 这条链体现了什么

```
问卷结论（大家想打卡、想要毛绒、常看小红书）
   ↓ 决定宣传说什么
文案包（主打打卡 + 毛绒 + 结伴）
   ↓ 决定海报写什么
海报长图（亮点、福利、报名方式）
   ↓ 汇总成完整页面
落地页（6 个区块，信息一致）
```

每一节的产出都是下一节的输入，后三节实践时学生把这套东西做成 PPT 和展板即可。

## 想让你判断的点

| 观察点 | 样例里的体现 |
|---|---|
| 成果是不是你熟悉的形态 | 问卷、文案、长图、落地页——都是活动和软件项目里的常见交付物 |
| 当堂做不做得完 | 文字类 1 页，网页类用现成结构填充；不需要设计功底 |
| 知识点有没有被检验 | 第 2 节看对比、第 4 节看对比记录，都是"说出为什么"而不是"做出好看的" |
| 后三节还有没有事做 | 有，但不命题——学生自己做 PPT、展板、路演 |

> 觉得哪件重了或轻了，直接说哪一件，我调规格。
