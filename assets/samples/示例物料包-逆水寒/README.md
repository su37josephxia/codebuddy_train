## 建议的浏览顺序

1. 先看 **⑦ 提案展板**——一眼看到整套成果的全貌。
2. 再看 **② 风格基调板**和 **③ 主视觉海报**——判断"当堂能不能做出这个颗粒度"。
3. 最后翻 **① 到 ⑥** 的文字物料——判断每件的颗粒度是否合适、是否过重。

## 这份样例想验证什么

| 观察点 | 样例里的体现 |
|---|---|
| 每件物料是否当堂做得完 | 文字物料都是 1 页表格；视觉物料用 Skill 生成而非手做 |
| 上一件是否真是下一件的输入 | Brief → 风格板 → 素材与主视觉 → 创意方案 → 文案 → 展板，链路完整 |
| 知识是否可检验 | ④ 对比报告考理解，⑦ 项目复盘写清组件搭配链路 |
| 成果是否拿得出手 | 7 件成册 + 展板 + 复盘，可直接进作品集 |

> 如果觉得某件过重或过轻，直接说哪一件，我调规格。
