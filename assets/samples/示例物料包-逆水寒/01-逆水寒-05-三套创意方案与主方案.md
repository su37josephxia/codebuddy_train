# 物料⑤　三套差异化宣发创意方案 + 主方案

> 样例组：第 01 组 ｜ 产出场次：第 5 场 ｜ 命名：`01-逆水寒-05-三套创意方案与主方案`

## 方案 A · 江湖夜雨（剧情向）

| 项 | 内容 |
|---|---|
| 主题 | 一入江湖，便是此生 |
| 切入角度 | 老玩家情感记忆，讲"江湖不是地图，是人际关系" |
| 视觉风格 | 雨夜、油纸伞、青石板，冷色调 + 一点暖灯 |
| 核心文案 | "十年前与你同行的那人，还在汴京等你吗？" |
| 适用渠道 | 老玩家召回、社媒长图 |
| 取舍理由 | 情感强但门槛高，新玩家看不懂 |

## 方案 B · 汴京烟火（场景向）

| 项 | 内容 |
|---|---|
| 主题 | 汴京灯火，照见江湖 |
| 切入角度 | 用场景质感打动人，讲"一个值得住进去的宋代江湖" |
| 视觉风格 | 夜市灯火、宋韵建筑、水墨远山，暖金 + 墨黑 |
| 核心文案 | "白天看山，晚上看灯，江湖就在烟火里" |
| 适用渠道 | 官网首屏、应用商店图 |
| 取舍理由 | 门槛低、视觉抓人，与风格基调板完全对齐 |

## 方案 C · 一刀入魂（战斗向）

| 项 | 内容 |
|---|---|
| 主题 | 刀光起处，故人归来 |
| 切入角度 | 动作爽感与竞技感，讲"手感与对抗" |
| 视觉风格 | 动态构图、冷光、快门感，高对比 |
| 核心文案 | "这一刀，等了十年" |
| 适用渠道 | 短视频、信息流广告 |
| 取舍理由 | 传播力强但偏离"克制、写意"的 Brief |

## 组内投票结果

| 方案 | 票数 |
|---|---|
| A 江湖夜雨 | 1 |
| **B 汴京烟火（主方案）** | **3** |
| C 一刀入魂 | 1 |

**主方案选定：B 汴京烟火。** 理由：三条宣发痛点里痛点 1 是"风格不稳定"，方案 B 最能用统一的东方美学解决它；A 和 C 保留为后续分渠道物料的备选。

> 该主方案即第 6 场文案实战与第 7 场展板的输入。
