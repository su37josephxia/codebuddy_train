## 建议浏览顺序

1. **先玩抽奖大转盘**——点几次，看是不是真随机、奖品对不对得上方案。
2. **再玩接蛋仔小游戏**——30 秒一局，判断"现场暖场"这个目标达没达到。
3. **看活动调研问卷**——注意它和前四节的报名问卷的区别（这份问满意度）。
4. **看数据分析报告**——重点看图表和"结论是不是可执行"。
5. **最后翻竞演 PPT**——10 页把前六节成果全串起来，这是结业路演的形态。

## 和前四节怎么接上

```
前四节（筹备）：宣讲PPT → 策划方案 → 报名问卷 → 文案/长图/落地页
                                                      ↓
第5节（执行）：抽奖大转盘 + 互动小游戏 ← 奖品池、亮点来自第2节方案
                                                      ↓
第6节（复盘）：活动调研问卷（收满意度）→ 数据分析报告（用问卷数据）
                                                      ↓
第7节（结业）：竞演PPT ← 把前六节全部成果汇总，5分钟路演
```

每个产出都能追溯到前面的输入：**转盘奖品来自方案奖品池、报告数据来自调研问卷、竞演 PPT 汇总前六节**。整套做下来，学生带走的是"一场活动从想法到落地"的完整闭环。

## 想让你判断的点

| 观察点 | 样例里的体现 |
|---|---|
| 交互是真的还是花架子 | 转盘真随机、游戏真能玩、PPT 真能翻，都能当场验证 |
| 和前四节数据一致 | 奖品、亮点、满意度、活动名前后统一 |
| 知识点有没有被检验 | 每个产出都要求"说清用了哪个组件"，竞演 PPT 第 7 页专门讲组件链路 |
| 学生做不做得完 | 都是单文件 HTML，用现成结构填充，不要求复杂开发 |
